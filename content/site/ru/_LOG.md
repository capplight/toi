## 2. Отступления от брифов и решения

1. **«кыз узату», «кудалык», «тусау кесер», «сундет той» без казахских букв.** Брифы требуют «1 раз в тексте», но тот же бриф ставит этот вариант и в H1, и в ключи первого абзаца / H2. Решение: H1 (задан брифом) + одно вхождение в первом абзаце; остальные ключи («текст приглашения на қыз ұзату», «сценарий қыз ұзату», «приглашение на құдалық») написаны в казахской орфографии. В `dastur-tusaukeser.md` 2 вхождения в тексте (первый абзац + ключ H2 «Приглашение на тусау кесер») — редактору решить.
2. **`dastur-sundet-toi.md`: бриф даёт title = H1** («Сүндет той: что это и как проводят»), это против README §7. H1 изменён на «…как его проводят».
3. **«!» в образцах текстов.** Восклицательные знаки есть только внутри пресетов (дословно), казахских тілек, их транслитерации и переводов. В редакционном тексте «!» нет.
4. **Пресет ru-besik-1 не использован** (бриф 4). Бесік той на /ru/priglashenie — абзац + kk-besik-1 с переводом.
5. **kk-тексты на ru-страницах.** На `shaqyru-tipy-sundet-toi.md` (1 текст) и `shaqyru-tipy-yubilei.md` (2 текста) пресетов kk не хватает — написаны короткие оригинальные kk-тексты с пометкой TODO на вычитку kk-автором. На `shaqyru-qyz-uzatu.md` бриф требует 2 текста «из kk-страницы» — её ещё нет, оставлены 2 пустые карточки с TODO (сейчас на странице 10 текстов, в description — 12).
6. **`pozdravleniya-na-kazakhskom.md`: 32 kk-тілек написаны ru-автором** (kk-страниц /kk/tilekter/* ещё нет). Транслитерация — скриптом по схеме брифа. Нужна проверка носителем; при появлении текстов kk-автора можно заменить. Народные формулы — только три из research §6 (S33, S33, S16) с пометкой «Народная формула». «Тойларың тойға ұлассын» — бытовая формула, близкая к «Мереке мерекеге ұлассын» [S34], подана без пометки «народная».
7. **Народные пословицы на страницах традиций**: «Келіннің бетін кім ашса — сол ыстық» [S3], «Жасына қарап отырып…», «Алыстан алты жасар бала келсе…» [S39], «Есіктен кіріп, төр менікі деме», «Төрдегі күлсе…» [S38], «Құда мың жылдық, күйеу жүз жылдық» [S26], «Жүйрік бол!», «Шауып кет!» [S10] — с маркером folk и переводом (перевод наш). Пословицы из S39 в research не помечены как «народные» явно — проверить О8.
8. **Имена этнологов** из S31 даны инициалами (С. Кульсариева, М. Егизбаева), как в research.
9. Ссылки на неопубликованные страницы (`/ru/traditsii/*`, `/kk/dastur/*`, `/kk/tilekter`) стоят; на `dastur-hub.md` — NOTE снять до публикации.

## 4. Чек-лист редактора (README §10) — самопроверка

- [x] Каждое утверждение о традиции с маркером источника; ✓-факты с «по одному из источников» / «как правило»; ⚠ — оба варианта (беташар: кто открывает лицо; тұсаукесер: кто режет, нож/ножницы; сырға салу: когда, золото; сүндет той: трон).
- [x] Советы — блоками «Наш совет», без «по традиции» / «так принято».
- [x] Блоки «НЕ писать» соблюдены (нет «молодые на төре» как традиции, сроков рассылки, текста Жансугурова, сумм калыма/киіт, «тақ жас», медицинских подробностей, «6 правил рассадки»).
- [x] Тексты приглашений и тілек — оригинальные, пресеты — дословно с подписью «образец текста». Поиск по точной фразе в Google **не выполнялся** (нет доступа в этой сессии) — сделать редактору на 10 случайных текстах.
- [x] Title ≤ 50 (+10), description ≤ 155, H1 ≠ title, основной ключ в первых 100 словах.
- [x] «вы» строчными, казахские термины в казахской орфографии, без эмодзи, без «(а)».
- [x] Плейсхолдеры не заменены.
- [x] Блок «Источники» и подпись «Проверка текста: {REVIEWER}, {REVIEW_DATE}» на страницах традиций.
