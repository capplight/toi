## 4. Что сдать

1. **`content/messages/kk.json`** — копия `_keys.json`, в которой **заполнены все значения**. Структуру и ключи не менять: ни добавлять, ни удалять, ни переименовывать.
2. **`content/NOTES_KK.md`** — заметки писателя (формат в разделе 6).

### Формат `kk.json`

- JSON в UTF-8, вложенные объекты, как в `_keys.json`. Отступ 2 пробела.
- Значения — сообщения ICU MessageFormat (next-intl). Переменные — ровно те, что указаны в колонке «Переменные» инвентаризации; имена переменных не менять.
- В kk `plural` обычно не нужен (после числа существительное в ед. ч.): `"{count} орын"`. Где по смыслу нужна особая форма для 1 — `{count, plural, =1 {…} other {…}}`.
- Варианты по типу тоя — `select`: `{kind, select, uilenu_toi {…} kyz_uzatu {…} sundet {…} besik {…} merey {…} other {…}}`.
- Переносы строк (WhatsApp, SMS) — `\n`.
- ASCII-апостроф `'` не использовать (ломает ICU). Кавычки — «».
- Разметка — только теги next-intl: `<b>…</b>`, `<link>…</link>`.

Пример:

```json
{
  "guests": {
    "list": {
      "total": "Барлығы: {families} отбасы · шамамен {seats} орын",
      "search": {
        "empty": "«{query}» бойынша ешкім табылмады"
      }
    }
  },
  "guestSheet": {
    "delete": {
      "confirm": "Тізімнен өшіру керек пе?\n{name}",
      "toast": "Өшірілді: {name}"
    }
  },
  "invite": {
    "date": {
      "countdown": "{days, plural, =1 {Той ертең} other {Тойға # күн қалды}}"
    }
  }
}
```

Если ключу по-вашему не нужен текст (например, пояснение лишнее), поставьте лучший короткий вариант и объясните в заметках — пустые значения не оставляйте.

## 8. Чего не делать

- Не переводить с русского и не смотреть сначала в ru-тексты: смысл — из колонки «Где» и `_context.json`.
- Не склонять переменные, не ставить союзы мен/бен/пен и порядковые суффиксы к переменным.
- Не придумывать функции, которых нет (офлайн у составителей, уведомления, автоматическое обращение по имени).
- Не использовать религиозные формулы и эмодзи в шаблонах.
- Не менять ключи и имена переменных.
- Не писать окончательные юридические тексты (`legal.*`, `invite.rsvp.consent`, `wizard.music.rights`) — только понятный черновик с пометкой «ЮРИСТ» в заметках.
