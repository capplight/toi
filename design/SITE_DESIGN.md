## 2. Шаблоны: назначение, блоки сверху вниз, адаптивность

### 2.1 T1 · Главная (`kk-home.html`, `ru-home.html`)
Назначение: коммерческий ключ «тойға шақыру» / «сайт-приглашение на свадьбу», объяснить 4 шага и увести в мастер или демо.

1. **Герой**: H1 (Cormorant, 38 → 60 px), вступление (первый абзац контента, 19 px), CTA `primary` «Шақыру жасау» → `/login?next=/e/new` + `secondary` «Демоны ашу» (`data-hero-cta`), строка доверия из 3 пунктов **[ВЫЧИТКА]** («WhatsApp арқылы · Қонақ ештеңе орнатпайды · Залда интернетсіз де жұмыс істейді»; ru: «Через WhatsApp · Гостю ничего не нужно устанавливать · Вход работает без интернета»). На телефоне CTA видны в первом экране 360×740 (проверено). На ≥ 900 — справа HTML-иллюстрация «WhatsApp → Келеміз → Сіздің үстеліңіз 7» (строки из `content/messages`), за ней шаңырақ.
2. **4 қадам** (`#qalai`, якоря `#tizim #shaqyru #otyrgyzu #komekshi` на карточках) — карточки с номером; 1 / 2 / 4 колонки.
3. **Қонақ не көреді** — текст + блок демо-приглашения (2.11-C).
4–7. **Фичи зигзагом**: текст + мини-UI (aria-hidden): списки «Әкесі/Анасы/Жастар», ответы + «Мейрамханаға: 240 адам → 24 үстел», схема зала, помощник у входа. На телефоне иллюстрация под текстом.
8. Расходы/печать/Excel — текст.
9. **Шақыру үлгілері** — 3 карточки шаблонов (на телефоне — строка «превью 96 px + текст», без карусели; с 768 — 3 колонки).
10. **Қай тойға** — плитки видов тоя (2 / 3 колонки); неопубликованное («Бесік той») — плитка «жақында» без ссылки.
11. Тілектер и дәстүр — абзац со ссылками.
12. **FAQ** (4 вопроса) + «Барлық сұрақтар».
13. **CTA-баннер** (заголовок **[ВЫЧИТКА]** — см. 4.13).
14. Футер. **Липкий CTA** на телефоне — появляется, когда CTA героя ушёл с экрана, прячется у баннера и футера.

ru-отличия: демо «Көк түн», цена `{PRICE}` → плашка «Цена {BRAND} — скоро» до Р10.

### 2.2 T2 · Хаб приглашений
Как T3, но блок 2 — **галерея из 3 шаблонов** (`template-cards buttons="Демоны ашу|Осы үлгімен жасау"`): карточка = превью-картинка 800×1000 (SEO-18) + видимая подпись «{Name} — тойға шақыру билеті үлгісі» + 2 кнопки; затем плитки видов тоя, сравнение «қағаз / сілтеме» (таблица), 12 текстов (2.11-B), советы, FAQ, CTA.

### 2.3 T3 · Приглашение по виду тоя (`kk-shaqyru-qyz-uzatu.html`)
1. Крошки «Басты бет › Шақыру › Қыз ұзату». 2. H1 (Onest), вступление, CTA «Шақыру жасау» → `/login?next=/e/new?kind=kyz_uzatu` (SEO-14a). 3. Оглавление (телефон — `<details>` «Мазмұны» свёрнут; десктоп — рейка + мини-CTA). 4. Описание шаблона + **демо-блок** + подпись «Демодағы есімдер… ойдан алынған». 5. **Тексты приглашения** группами (Үлгі мәтіндер · Ресми · Жылы · Қысқа (WhatsApp) · Екі тілде): карточка + «Көшіру» + «Осы мәтінмен жасау»; `[есімі]` подсвечено как поле для вписывания; ru-строка двуязычного текста — под чертой, `lang="ru"`. 6. Совет. 7. Кого зовут; рассадка + иллюстрация «Отырғызу реті» (категории с ромбами-оттенками из DESIGN_v2 3.2). 8. Еске салу (текст 15). 9. FAQ. 10. Ссылки + «Осы тойға қатысты» (4 карточки). 11. CTA-баннер. Липкий CTA на телефоне.

### 2.4 T4 · Демо-шаблон
Рендерер `/i/{token}` (без изменений, DESIGN_v2 8.17) с фикстурой. Сверху — тонкая полоса сайта 56 px: знак {BRAND}, «Демо» и «Осы үлгімен жасау»; снизу под письмом — H1 страницы (««Қызғалдақ» шақыру үлгісі»), разделы «Қандай», «Қай тойға лайық», CTA и «WhatsApp-қа жіберу» (share). Форма ответа ничего не пишет (SEO-08). Музыка только по «Ашу».

### 2.5 T5 · Хаб тілек (`kk-tilekter.html`)
H1 (Cormorant — хаб), вступление; «Кімге айтасыз?» — 10 плиток поводов (2 / 3 / 5 колонок); затем раскладка T6: фильтр («Түрі»: Барлығы · Өлеңмен · Бата; «Ұзындығы»), группы «Ең жақсы 20» (подзаголовки по поводам), «Қысқа», «Өлеңмен»; «Тілек пен батаның айырмашылығы» (там же «халық аузынан» — мақал), совет, этикет, FAQ, баннер «Өз тойыңызға дайындалып жүрсіз бе?». Крошек нет (первый уровень).
ru-вариант (`/ru/pozdravleniya-na-kazakhskom`): карточка T6 + строки «Как читать» (транслитерация) и «Перевод» под чертой, `lang="kk"` на казахском тексте; копируется только казахский текст (переключатель «копировать с переводом» — [ВОПРОС] 6).

### 2.6 T6 · Страница тілек (`kk-tilekter-sundet-toi.html`)
1. Крошки. 2. H1 (Onest 28 → 40), вступление. 3. **Фильтр** (`<details class="filter">`): телефон — свёрнут, в заголовке счётчик «Көрсетілді: 60 / 60»; десктоп — в правой рейке, раскрыт, sticky. Внутри: «Кімге, кімнен» (Барлығы · Балаға · Ата-анасына · Атасы мен әжесінен · Нағашыларынан), «Ұзындығы» (Барлығы · Қысқа · Орташа · Ұзақ), статус + «Сүзгіні тазалау», «Бөлімдер» — якоря групп (`#balaga … #qysqa #olenmen #aq-bata`). 4. **Группы** = H2 из контента, внутри карточки (2.11-A). Пустой результат — «Бұл сүзгі бойынша тілек жоқ» + сброс. 5. «Балаға не сыйлайды» — **расхождение источников** (два этнолога). 6. «Тілекті қалай айту керек» — совет. 7. FAQ. 8. Ссылки, «Осы тойға қатысты», мягкий CTA-баннер. **Липкого CTA нет** (человек пришёл за текстом; липкая полоса мешала бы читать и закрывала бы тост).
Число карточек = числу в title (SEO-17): 60.

### 2.7 T7 · Хаб традиций
H1 (Cormorant), вступление (с фразой «Деректер әртүрлі болған жерде екі нұсқаны да береміз» — это и есть обещание компонента 4.5), два нумерованных списка-группы («Үйлену циклы», «Бала туғаннан кейін») как карточки-ссылки (`rel-cards`), блок «Той сөздігі», ссылки, подпись проверяющего.

### 2.8 T8 · Статья обряда (`kk-dastur-betashar.html`)
1. Крошки «Басты бет › Дәстүр › Беташар». 2. H1, **определение — первым абзацем** (`lead`, цитируемо для AIO). 3. Мета: «Жаңартылды: {UPDATED} · Тексерген: {REVIEWER}» (из frontmatter `updated`, `reviewedBy`). 4. Оглавление из H2. 5. Тело: факт-плашка (ЮНЕСКО, 2024), цитата (`blockquote` + `cite`), «Халық аузынан», нумерованные шаги с крупными номерами, внутри шага — «Деректер әртүрлі», совет редакции, заметка о содержании (пунктир, «i»), таблица «Не керек» + «Тізімді басып шығару» (`window.print()` + print-CSS), словарь «Мақаладағы сөздер», FAQ. 6. «Осы тойға қатысты». 7. **Дереккөздер** (нумерованный список, якоря `#src-N`, хост ссылки видно). 8. «Мәтінді тексерген …». 9. CTA-баннер. Десктоп: рейка — оглавление (подсветка текущего раздела) + мини-CTA «Үйлену тойына шақыру».
Вариант-словарь (`toi-sozdigi`): `<dl>` с якорем на каждый термин (`{#tor}` из контента), алфавитная полоса-якоря сверху, без оглавления.

### 2.9 T9 · Функция (`ru-rassadka-gostei.html`)
Как T8 + продуктовые блоки: CTA в шапке статьи, **«Традиция · как описано для дома»** (золотая метка с қошқар мүйіз) → пословицы → **«Как делают сегодня»** (песочный блок) — визуально разведены; схема зала (`<figure>` + `<img alt>` + подпись), таблица столов + **калькулятор** (форма GET, работает без JS; результат `role="status"`), 2 совета (второй с нумерованным списком), «План рассадки онлайн» (шаги), скриншот «Зал» (фиктивные данные), FAQ, «По теме», источники, баннер. Липкий CTA на телефоне.

### 2.10 T10 · Служебные
- **FAQ**: H1, вступление, группы H2 («Шақыру», «Тізім және жауап», «Отырғызу»…) + аккордеон; скрытые вопросы (`HIDDEN`) не рендерятся и не попадают в JSON-LD. Сверху — якоря групп (`group-nav`).
- **О нас / Контакты**: колонка чтения; контакты — 2 крупные кнопки «WhatsApp» (`wa-fill`) и «Пошта», плейсхолдеры `{SUPPORT_WHATSAPP}`, `{EMAIL}`, `{SUPPORT_HOURS}` до решения (Q7).
- **Цены** (`/kk/baga`, `/ru/tseny`) до Р10: страница-заглушка «Баға жақында» (компонент 4.12), `noindex`, ссылки на демо и FAQ; в меню пункт «Баға» с меткой «жақында» (см. [ВОПРОС] 1).
- **404** (SEO-16): H1 «Бет табылмады» **[ВЫЧИТКА]**, 4 плитки хабов, статус 404.

### 4.1 Карточка тілек + фильтр
- **Строка меток**: «№ 14» (ink-2) · длина — значок «три столбика» (заполнено 1/2/3) + слово `қысқа / орташа / ұзақ` (sr-only префикс «Ұзындығы:») · `өлең` (lapis-soft) · `бата` (success-soft) · **`халық батасы`** / `халық аузынан` (gold-soft + значок «кавычки» + рамка) — для текстов с маркером `folk` · `атасынан / әжесінен` — контурная метка (сейчас в тексте «(атасынан) …» — парсер выносит в метку; лучше атрибут `from=`, [ВОПРОС] 5).
- **Текст** 19/30, `user-select: text` (долгое нажатие тоже работает), стихи — построчно (`white-space: pre-line`).
- **Действия** (сетка 2 колонки, на 320 переносятся): `Көшіру` (контур) и `WhatsApp` (контур зелёный, `aria-label="WhatsApp-қа жіберу"`). 48 px.

Енді WhatsApp-қа немесе SMS-ке қоя аласыз.» **[ВЫЧИТКА]** (`role="status"`), через 2.5 с всё возвращается (`#copied`). Буфер недоступен (старые WebView в мессенджерах) → тост «Көшірілмеді. Мәтінді басып тұрыңыз — «Көшіру» шығады.» **[ВЫЧИТКА]** (`#copy-fail`). Копируется чистый текст без номера и меток.
- **WhatsApp**: в HTML `href="https://wa.me/?text=<URL карточки>?utm_source=tilek_share#tN"` (лёгкий HTML, работает без JS — делится ссылкой на конкретный текст); островок по нажатию подставляет `текст + \n\n + ссылка`. В ссылке нет персональных данных (SEO-17). Событие `whatsapp_share`.

Группа без видимых карточек скрывается целиком. URL не меняется (SEO-17). Состояния: `#filter`, `#filtered`.

Егизбаева» / «Этнолог С. Құлсариева»), разделитель пунктиром; ≥ 640 px — рядом, на телефоне — друг под другом; необязательная строка-вывод из текста («Яғни … екі түрлі»). ### 4.6 Заметка редакции (`note`)
Пунктир + «i»: пояснение о самой странице («толық мәтін берілмеген»). Не совет и не традиция.

### 4.7 Источники и сноски
- Список «Дереккөздер / Источники» в конце статьи: `<ol>`, `id="src-N"`, название и дата — текстом, ссылка — **хост** (`ich.unesco.org`) + значок внешней ссылки, `rel="noopener" target="_blank"`. `:target` подсвечивается.
- **Сноска** `[1]` — ссылка на `#src-N` внутри строки (16 px, без уменьшения кегля; исключение WCAG 2.5.8 для ссылок в тексте). В макете проставлены только там, где соответствие точно известно (ЮНЕСКО → 1, Б. Жұмабайұлы → 4). Метки `<!-- S1 S3 -->` в контенте — глобальные ID исследования, не номера списка: нужна таблица `S-ID → пункт списка` от контент-лида ([ВОПРОС] 4). Без неё сноски не выводить — атрибуция в тексте («ЮНЕСКО сипаттамасында…») уже есть.
- «Мәтінді тексерген: {REVIEWER}, {REVIEW_DATE}» — плашка со щитом-галочкой; для `dastur` обязательна (CONTENT_PLAN 5.4).

### 4.8 FAQ-аккордеон
`<details><summary><h3>Вопрос</h3>…</summary><div>Ответ</div></details>` — нативно, без JS, работает с клавиатурой; закрытые ответы есть в HTML (индексируются). Цель 56 px, кружок-шеврон поворачивается. JSON-LD **FAQPage** — из тех же данных (текст видимых вопросов и ответов дословно; `HIDDEN` — нет). Состояние `#faq` — все раскрыты. На главной/FAQ первый вопрос можно открыть по умолчанию ([ВОПРОС] 8).

### 4.9 Оглавление
Из H2 страницы. Телефон: `<details>` «Мазмұны / Содержание» 56 px после вступления (свёрнуто, `#toc`). Десктоп: правая рейка, sticky, пункты 44 px, подсветка текущего раздела (`aria-current`, островок IntersectionObserver). Для T6 вместо оглавления — «Бөлімдер» внутри фильтра.

### 4.10 Словарь терминов
- Страница-словарь: `<dl>`, якорь на каждый термин.
- В статье: блок «Мақаладағы сөздер» / «Слова из статьи» **[ВЫЧИТКА]** — 2–4 термина с определением **из `dastur-toi-sozdigi.md`** (в макете: Көрімдік, Шашу) + ссылка «Той сөздігі». Термин — пунктирное золотое подчёркивание, ссылка на `#якорь` словаря (всплывающих подсказок нет — неудобны на телефоне и для 50+).

### 4.11 Плитки
Виды тоя / поводы тілек: 64 px, стрелка, 2 / 3 / 5 колонок. Неопубликованная страница — плитка с пунктиром и «жақында», **без ссылки** (SEO-07/13: ссылки на неопубликованные страницы — текстом).

### 4.12 «Скоро» / скрытые разделы
- Плашка `soon-badge` «жақында / скоро» (gold-soft) — в меню («Баға»), в плитках, вместо `{PRICE}`.

### 4.13 CTA
- `CtaRow`: CTA сразу после вступления — в шапку статьи (`primary` + `secondary`), во всю ширину на телефоне (< 480), в ряд на десктопе.
- `CtaBanner` — последний CTA страницы: ночная плашка, Cormorant 32 → 44, текст on-night-2, кнопка gold (night на gold-bright 7.96:1), шаңырақ в углу. **Заголовок и текст баннера** в контенте не заданы — предлагаю поле frontmatter `cta: {title, text}`; в макетах — строки дизайнера **[ВЫЧИТКА]**: «Тізімнен үстел нөміріне дейін — бір жерде», «Сүндет тойға қонақ шақырасыз ба?», «Үйлену тойына шақыру жасаңыз», «Қыз ұзату тойына шақыруды бүгін жасаңыз», «Приглашение на той — за один вечер», «Составьте план рассадки онлайн». ## 6. Реализация на Next.js 16 App Router + Tailwind v4

### 6.1 Структура
- Группа маршрутов `(site)/[locale]/…`, Server Components, SSG/ISR; без клиентского i18n-бандла. Контент — MDX (`content/site/**`, SEO-07), BLOCK-маркеры → MDX-компоненты (таблица §4).
- **Токены**: те же переменные, что в `tokens.css` → `@theme` в Tailwind v4; новые сайтовые: `--on-night-2 #C9BFAE`, `--h-header`, `--measure 42rem`, `--wrap 75rem`. Классы `site.css` — эталон для перевода в утилиты/компоненты.
- **Клиентские островки** (`"use client"`, каждый маленький): `CopyButton`, `TilekFilter`, `WhatsAppShare` (подмена href по клику), `StickyCta`, `TocSpy`, `MenuCloser` (Esc/навигация), `TableCalc`. Всё остальное — сервер. Цель SEO_PLAN 5.7: JS ≤ 90 КБ gzip; островки сайта ≈ 10–15 КБ.
- Меню, оглавление, FAQ, обёртка фильтра — нативные `<details>`: работают до гидратации.

### 6.2 Производительность (SEO-12: Lighthouse mobile ≥ 90)
- **LCP** — текст H1: над первым экраном телефона нет картинок (иллюстрация героя только ≥ 900 px и это HTML/CSS). Превью шаблонов — ниже первого экрана, `loading="lazy"`, `next/image` с `sizes`; `priority` не ставить никому, кроме случая, когда превью реально в первом экране (T4).
- **Шрифты**: `next/font/google` (self-host, без запроса к Google в рантайме), Onest 400/600 + Cormorant 600, `subsets: ['cyrillic','cyrillic-ext','latin']`, `display: 'swap'`, `preload` — только начертание H1 (Cormorant на T1/T5/T7, Onest 600 на остальных). Если будут свои подмножества из `design/v2/assets/fonts` — **добавить `[ ] ›`** (в текущих подмножествах нет U+005B, U+005D, U+203A; в макете их рисует запасной шрифт), иконки — только SVG.
- **CLS**: у всех `img` есть `width/height`; липкий CTA — `transform`, а не смена высоты; шапка фиксированной высоты.
- Без `backdrop-filter`, без видео, без карусели. Вес HTML макетов: 28–34 КБ (статьи), 66–77 КБ (хаб/страница тілек с 38/60 карточками; ≈ 12–15 КБ gzip).
- `prefers-reduced-motion` отключает все переходы.

### 6.3 Что нужно от контента (для компонентов без маркеров)
