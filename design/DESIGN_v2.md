## 0. Коротко

**Направление: «тихая роскошь степного праздника».** Тёплая бумага цвета слоновой кости, глубокий лазурит (көк) как рабочий цвет, золото только тонкой линией. Два мотива со смыслом вместо «узора ради узора»: **шаңырақ** (венец юрты = дом, семья; с лучами-уықтарами он же солнце) и **қошқар мүйіз** (достаток). Третий мотив — **степной тюльпан** — только в одноимённом шаблоне. Всё нарисовано тонкой линией в SVG и **«рисуется» на глазах** (stroke-dashoffset), а не вставлено картинкой.

| Решение | Что выбрано |
|---|---|
| Шрифты | **Onest** 400/600 (интерфейс) + **Cormorant Garamond** 600 (праздничные заголовки и имена, **только от 20 px**). 2 семейства, 3 начертания, 18/18 казахских букв. Страница гостя: свои woff2-подмножества Cormorant 600 + Onest 400 = **29.8 КБ** (`assets/fonts/`) |
| Цвет | `--ivory #F7F2E9` фон, `--lapis #1C3B5E` действие (белый текст 11.4:1), `--gold #B48A3E` только графика, `--night #0F2338` парадные плашки |
| Рабочие экраны | Чистые, крупные; праздник — только в парадной шапке события, у стола молодых и в «Қосылды!». Анимации ≤ 300 мс, по делу |
| Страница гостя | Конверт с именем семьи (именительный падеж) и сургучом-монограммой «А/Д» → «Ашу» (музыка) → клапан открывается в 3D, письмо выезжает, орнамент рисуется. **Обычный HTML без React** (route handler, план 1.3/10) + CSS + инлайновый SVG + ванильный островок ≤ 10 КБ (всего JS ≤ 15 КБ); ответ — обычная форма `POST`, работает без JS |
| Шаблоны | «Ақ шаңырақ» (день, слоновая кость), «Көк түн» (вечер, ночное небо), «Қызғалдақ» (гранат и тюльпаны) |
| Телефон: первый экран | «Зал»: сводка в одну строку, статус-чипы, сегмент в шапке — «ТӨР», стол молодых и первый ряд видны сразу даже при всех проблемах (B1). «Менің тізімім»: компактная шапка — первая карточка гостя и «Қонақ қосу» видны сразу (N1) |

## 1. Принципы

1. **Логика v1 неприкосновенна.** Сценарии, состояния, тексты и геометрия зала из `design_spec` не меняются (кроме H5 по решению Р4, см. 8.15). Меняется только внешний вид и раскладка на больших экранах.
2. **Одно главное действие на экране**, всегда в одном месте: внизу у большого пальца на телефоне, в шапке страницы справа на десктопе.
3. **Праздник дозирован.** Чем рабочее экран, тем меньше декора. Шкала: страница гостя (максимум) → вход/успех/шапка события (средне) → списки, формы, зал (только стол молодых и линия «ТӨР»).
4. **Орнамент — линия, а не заливка.** Тонкая золотая линия 1.2–1.6 px, без теней, «тиснения» и красно-золотой «ковровой» гаммы. Орнамент никогда не стоит **за текстом** рабочих экранов (в парадной шапке он уходит за край карточки, текст свободен).
5. **Движение объясняет или празднует, но не мешает.** Каждая анимация имеет длительность, кривую, триггер и вариант для `prefers-reduced-motion` (раздел 6).
6. **Цвет никогда не единственный признак** (заливка/контур/значок/слово), как в v1.
7. **Знакомое**: шторка снизу как в WhatsApp/Kaspi, зелёная кнопка WhatsApp, бумажный план зала.
8. **Легко для слабого телефона**: SVG и CSS вместо картинок и видео; на странице гостя — ничего, что требует большого JS.

### 3.4 Типографика

**Проверка шрифтов (2026-10-09).** Скачаны TTF из репозитория `google/fonts`, проверена таблица `cmap` скриптом fontTools на 18 букв: ә ғ қ ң ө ұ ү һ і Ә Ғ Қ Ң Ө Ұ Ү Һ І.

| Шрифт | Результат |
|---|---|
| **Onest** (переменный 100–900) | ✓ 18/18 |
| **Cormorant Garamond** (переменный 300–700) | ✓ 18/18 |
| Cormorant, Cormorant Infant, Playfair Display, Prata, Forum, Literata, Lora, Alice, Spectral, Ysabeau, Yeseva One, Golos Text | ✓ 18/18 (запасные варианты) |
| Oranienbaum, Tenor Sans | ✗ нет 16 из 18 |
| Manrope, Unbounded | ✗ (как в v1) |

Почему эти: **Onest** — современный гротеск с крупной высотой строчных и открытыми формами (ғ/г, қ/к, ү/у различимы на 16 px), выглядит дороже, чем «государственный» Golos. **Cormorant Garamond** — классическая антиква с высоким контрастом штрихов: на 24–76 px даёт ощущение печатного приглашения. Мелким текстом её не используем (тонкие штрихи).

**Начертания (всего 3 из разрешённых 4):** Onest 400, Onest 600, Cormorant Garamond 600.
Подключение в рабочих экранах: `next/font/google`, `subsets: ['cyrillic','cyrillic-ext','latin']`, `display: 'swap'`.
**Страница гостя (решение ревью 3.1):** только **свои woff2-подмножества** (`pyftsubset`/fontTools: казахский и русский алфавит, латиница, цифры, «»—·–₸ и знаки), Google Fonts не используется: `assets/fonts/cormorant-garamond-600-kk.woff2` 19.5 КБ + `assets/fonts/onest-400-kk.woff2` 10.4 КБ = **29.8 КБ** (лимит 40). Оба проверены после сжатия: 18/18 казахских букв. `preload` — только Cormorant (имя семьи на конверте = LCP). Для рабочих экранов подготовлен и `onest-600-kk.woff2` 10.9 КБ (если решат отказаться от Google Fonts и там).

**Правило Cormorant ≥ 20 px.** Cormorant Garamond используется только для текста от 20 px: имена, приветствие, заголовки карточек, число дня, месяц, «Ашу», номер стола. ## 6. Спецификация движения

Кривые: `--ease-out cubic-bezier(.2,.8,.2,1)` (появление), `--ease-in cubic-bezier(.4,0,1,1)` (уход), `--ease-inout cubic-bezier(.65,0,.35,1)` (конверт, перестановки), `--ease-draw cubic-bezier(.45,.05,.25,1)` (рисование линии).
Реализация: страница гостя — **только CSS keyframes/transitions** (+ класс от ванильного островка, без React). Рабочие экраны — CSS для мелочей, **Motion** (`LazyMotion` + `domAnimation`) только для шторок/панелей, списков и перестановок (H5), как в плане (раздел 2).
`prefers-reduced-motion: reduce` — глобально: движение (transform) выключено, остаётся смена прозрачности ≤ 250 мс, орнаменты сразу нарисованы, ничего не мерцает и не крутится. Проверено скриншотом `05-invite-ak-shanyraq_open_360_rm_full.png`.

## 11. ИИ-обложки (решение Р6)

**Я не могу генерировать изображения.** Ниже — направление, промпты, процесс и критерии отбора; прогоны делает основатель (бюджет Р13 ≤ $20) в Midjourney v7 / FLUX 1.1 / Ideogram / Nano Banana — любом, что даёт чистую живопись без текста.

## 12. Производительность страницы гостя (план v1.2, раздел 10)

Страница гостя — **обычный HTML без React-рантайма** (решение ревью 3.4): route handler + `renderToStaticMarkup`, ванильный островок ≤ 10 КБ, **всего JS ≤ 15 КБ**, всё до музыки ≤ 150 КБ. Ранее заявленные «JS ≈ 2–3 КБ» верны только для такой страницы, не для RSC-страницы App Router (~90–110 КБ рантайма).

Измерено по макетам (gzip -9) и собранным подмножествам шрифтов (2026-10-09):

| Часть | Вес | Комментарий |
|---|---|---|
| HTML с инлайновым SVG-декором | 6.3–6.9 КБ gz | Все три шаблона (с формой `POST` и островком) |
| CSS приглашения (`invite.css`) | ≈ 7.6 КБ gz | В продукте — этот CSS как есть (без Tailwind-рантайма), инлайном или одним файлом |
| JS-островок | 0.7 КБ gz в макете (1.6 КБ без сжатия); бюджет ≤ 10 КБ | Конверт (классы), `audio.play()`, −/+, скрытие числа мест, `IntersectionObserver`-пауза, `visibilitychange`, `sendBeacon` пинга |
| Шрифты | **29.8 КБ**: Cormorant Garamond 600 19.5 + Onest 400 10.4 (`assets/fonts/*.woff2`, 18/18 казахских букв) | Свои подмножества, Google Fonts нет; `preload` только Cormorant |
| Обложка | ≤ 60 КБ AVIF/WebP | раздел 11 |
| **Итого до музыки** | **≈ 105 КБ** с обложкой, ≈ 45 КБ без | ≤ 150 КБ ✓ |

Анимации на странице гостя — только `transform`, `opacity`, `stroke-dashoffset`; одновременно ≤ 60 элементов; бесконечные — на паузе вне экрана и в фоновой вкладке (6.1); `will-change` глобально не ставим. `animation-timeline: view()` — прогрессивное улучшение (Chrome/Edge 115+, Safari 26+; Firefox — [ПРОВЕРИТЬ] в Ф5, N14); без поддержки блоки видны сразу. 3D-конверт проверить во встроенном браузере WhatsApp на бюджетном Android, запасной вариант `html.lite` (6.1, N5).
