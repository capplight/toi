## 1. Цель

Экран «Қорытынды» (`/e/[eventId]/summary`) показывает хозяину и составителям главное число для ресторана, итоги ответов, разбивку по категориям, воронку приглашений и итоги по спискам. Это последняя экранная фаза перед подготовкой релиза A.

## 2. Задачи

- [ ] Данные — один серверный запрос-сборка `summaryView(eventId)` (`requireMember`). Числа считают функции домена, без своих формул:
  - **«Мейрамханаға: N адам → M үстел»** — `totals(state)`: N = к рассадке, M = занятые столы. Если зала нет — только «N адам» и подсказка `summary.restaurantHint` (настроить зал);
  - **плитки:**
    - «Келеді · семьи · места» (подтверждённые);
    - «Жауап жоқ · семьи · ~места» — **включая не отправленных** (А4), под числом `summary.tiles.pendingNotSent` с их количеством;
    - «Келмейді · семьи»;
  - **по категориям:** горизонтальные полосы (без круговых диаграмм), места к рассадке по категории, порядок — ранг рассадки;
  - **воронка:** отправлено (`sent_at`) → открыли (`first_opened_at`) → ответили (`responded_at`, в том числе ответы по телефону) + подсказка `summary.funnel.hint`. Видна хозяину (DESIGN 8.19), составителям — нет;
  - **по спискам:** составители (подпись + имя) с числом семей и мест, ссылки на их списки (как «Басқа тізімдер» Ф4);
  - **карточка «Шығындар»** — только при `can_manage_budget`. До Ф9 — ссылка на заглушку `/budget`, без сумм (суммы появятся в Ф9).
- [ ] Экран по 8.19:
  - 360: компактная шапка события, главное число в карточке lapis-soft, 3 плитки, полосы, воронка, списки, карточка расходов;
  - десктоп: 12-колоночная сетка.

  Компоненты Ф1: `CounterTile`, `ProgressBar`, `LinkRows`, `EventHero`. Пустое событие — `summary.empty`.
- [ ] Обновление: серверный рендер при каждом заходе, плюс опрос `seating_version` раз в 15 с, пока вкладка видна (план 7.5). Версия растёт на любом изменении рассадки и ответов по правилу П1 Ф4, поэтому опрос ловит и ответы гостей.

## 3. Тесты

- [ ] **unit / integration:** `summaryView` на сиде совпадает с `design_spec` 5.2:
  - 150 подтверждённых мест;
  - «Жауап жоқ» 9 семей / ~23 места, из них 2 не отправлены;
  - «Келмейді» 3 семьи;
  - к рассадке 173 места;
  - «Мейрамханаға 173 → 15 үстел».

  Плюс: события без зала и без гостей; доступ (403 чужому, воронка не видна составителю).
- [ ] **e2e (360 и 1440, kk и ru):**
  - экран совпадает со скриншотами дизайна 8.19 (в макетах нет отдельного файла — по описанию);
  - ответ гостя через `/i/{token}` меняет цифры после опроса;
  - «Шығындар» не виден «Жастар»;
  - axe, 130 %, 320 px.

## 4. Критерии приёмки

1. Числа совпадают с `design_spec` 5.2 и считаются функциями домена.
2. «Жауап жоқ» включает не отправленных и показывает «оның ішінде жіберілмеген: N» (А4).
3. Воронка видна только хозяину.
4. Экран по 8.19; доступность и 130 % без поломок.
5. Все проверки зелёные.
