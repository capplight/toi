## 1. Цель

За 1–2 дня до тоя хозяин включает показ номеров столов и рассылает каждой семье номер через WhatsApp, по очереди, без ручного поиска. Гость видит свой стол на странице приглашения. В день тоя помощник у входа открывает свою ссылку один раз при интернете. Дальше без сети он находит семью по 2–3 буквам, видит стол и отмечает «Келді». Отметки синхронизируются, когда сеть появится.

## 2. Номер стола

- [ ] Миграция: `events.show_table_numbers boolean not null default false` (расширяющая). Переключатель `settings.showTableNo` у хозяина (Баптаулар).
- [ ] **Страница гостя** (Ф5, тегированные строки): если флаг включён и у семьи есть стол — блок «Сіздің үстеліңіз»:
  - номер Cormorant 96–140, «үстел»;
  - **мини-схема на сервере** — SVG из `layoutTables` (ТӨР, стол молодых / «Құрметті үстел», кружки столов, свой — с пульсирующим кольцом G19), **без имён соседей**;
  - `invite.table.hint` — только если ссылку помощника уже открывали (`activity_log` или отметка в `events`);
  - нет стола → `invite.table.notYet`.

  Бюджет страницы Ф5 сохраняется: мини-схема ≤ 4 КБ.
- [ ] **Очередь «Үстел нөмірлерін жіберу»** (8.18), `/e/[eventId]/table-queue`, только хозяин и родители с правом рассадки:
  - сверху «34 / 120» и полоса;
  - карточка текущей семьи (имя, «10-үстел», телефон, предпросмотр текста `wa.tableNumber`);
  - большая «WhatsApp-та ашу» (`location.assign`, ревью Ф3);
  - после возврата — «Келесі →» (= `markSent(kind='table')` → `table_sent_at`, решение 3.2 ревью дизайна: без вопроса «Жіберілді ме?») и «Өткізіп жіберу»;
  - «Тоқтату»; при повторном входе — «Тоқтаған жерден жалғастыру (N-ші)» по `table_sent_at`.

  Порядок — по номеру стола, затем по имени. Семьи без стола и без телефона — в конце, с `tableQueue.notSeatedNote`.

  Вход — `summary.tableQueueEntry` на «Қорытынды» и пункт в меню хозяина. На десктопе очередь слева, карточка справа.

## 3. Помощник на входе `/d/{doorToken}`

- [ ] Включить блок «Кіреберіс сілтемесі» в составителях (убрать флаг `NEXT_PUBLIC_FEATURE_DOOR`); «WhatsApp-қа жіберу» с `wa.doorLink`; «Жаңа сілтеме» → `rotateDoorToken` (старый снимок на устройствах перестаёт синхронизироваться: `door.status.linkRevoked`).
- [ ] **Сервер** (план 6.6):
  - `GET /api/door/{token}/snapshot` → `{event: {title, startsAt}, tables, families: [{id, name, tableNo, seats, categoryLabel, rsvp, arrived}], generatedAt}` — **без телефонов**, `no-store`;
  - `POST /api/door/{token}/checkins` → `{deviceId, ops: [{opId, familyId, arrived, clientAt}]}`, идемпотентно по `opId`, ответ — актуальные отметки; при споре побеждает более поздний `clientAt`; `families.arrived_at` и `door_checkins`;
  - лимит 600 в час на токен;
  - неизвестный или отозванный токен → 404.
- [ ] **Клиент:**
  - **Serwist**, scope `/d/`: precache оболочки (HTML страницы помощника, JS, CSS, шрифт), остальной сайт без service worker;
  - **IndexedDB** (`idb`): `snapshot`, `outbox`;
  - поиск локальный: нижний регистр, `ё → е`, совпадение с началом любого слова, 2–3 буквы, подсветка совпадения;
  - «Келді» → `outbox` + мгновенное обновление;
  - синхронизация при `online`, раз в 30 с и при открытии;
  - тихое обновление снимка, если он старше 2 ч и есть сеть;
  - `OfflineIndicator`: «Тізім телефонға сақталды · N адам · время» / «Интернет жоқ · әлі жіберілмеді: N»;
  - «Белгіні алу»; тост сверху 4 с с «Қайтару» (ревью дизайна N10);
  - Background Sync не используем (iOS).
- [ ] Первое открытие без сети → `door.status.firstLoadNeedsNet`.
- [ ] Страница помощника — без вкладок и меню, крупно, контрастно (8.21). На десктопе — «Соңғы келгендер» справа.

## 4. Тесты и приёмка

- **integration:**
  - снимок без телефонов;
  - отметки идемпотентны (повтор `opId`);
  - два устройства с разным `clientAt`;
  - отозванный токен → 404;
  - лимит;
  - `show_table_numbers` выключен → номера на странице гостя нет;
  - очередь: порядок, продолжение с места остановки.
- **e2e:**
  - помощник: загрузка → `context.setOffline(true)` → поиск → «Келді» → перезагрузка офлайн (service worker отдаёт оболочку) → сеть → отметка в базе; два контекста-устройства сходятся;
  - очередь: «WhatsApp-та ашу» (`href` `wa.me` корректный) → «Келесі» → `table_sent_at`;
  - страница гостя с номером и мини-схемой (360, 320, 1440); бюджет Ф5 соблюдён;
  - axe, 130 %.
- Приёмка по плану 12.3 Ф8. Проверка в режиме полёта на реальном Android и iPhone — в дополнении после аккаунтов.
