## 3. Решения по правилам «Қайтару» (расширение разработчика)

Разработчик убрал «Қайтару» шире брифа. **Принимаю:**
- **операции списка** (`added`, `deleted`, `restored`, `seats`, `answerReverted`, `categoryAdded`) — у них своя отмена в S1 / H6 (тост), а отмена «посадки» из истории зала сняла бы семью со стола, не вернув сам список в прежнее состояние. Это запутает родителей;
- **первая настройка зала** (`hall.before = null`) — отменить её значит снять со столов всех. Нельзя одним нажатием;
- **ответ по телефону** — отменяет только его автор (`revertAnswer`, П2 ревью Ф4); ответы гостей — без отмены.

Для удалённой семьи после закрытия тоста вернуть её из истории нельзя. Для пилота допустимо; если родители попросят, это отдельная «корзина» после пилота.
