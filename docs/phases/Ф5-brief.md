## 1. Цель

Семья открывает персональную ссылку из WhatsApp и видит:
- конверт со своим именем;
- после «Ашу» — музыку и красивое приглашение одного из трёх шаблонов;
- форму ответа: «Келеміз / Келе алмаймыз», число мест.

Ответ сразу попадает к составителям и в рассадку. Страница быстрая на слабом интернете и работает даже без JS.

Хозяин загружает музыку. В мастере и в настройках виден настоящий предпросмотр приглашения. Превью ссылки в WhatsApp — персональная OG-картинка.

**Не входит:** номер стола на странице гостя и подсказка `invite.table.hint` (Ф8); ИИ-обложки как файлы — их генерирует основатель (Р13). Шаблоны работают на SVG-заставках, обложки подключаются, когда появятся.

## 2. Решения (не обсуждаются в фазе)

| Тема | Решение |
|---|---|
| **Технология страницы** | `src/app/i/[token]/route.ts` отдаёт готовый HTML. Шаблоны — TSX-компоненты, которые `react-dom/server` `renderToStaticMarkup` превращает в строку без гидратации. Встроенный ванильный островок ≤ 10 КБ: конверт, музыка, отправка формы, `sendBeacon`. **День 1 — спайк**: проверить, что импорт `react-dom/server` в route handler работает в standalone-сборке. Если нет — шаблоны на тегированных строках с обязательным экранированием (`html\`\``). Результат спайка — в handover |
| Бюджеты (план 10) | JS ≤ 15 КБ gzip всего; всё до музыки ≤ 150 КБ; LCP ≤ 2,5 с (Slow 4G, mobile); CLS ≤ 0,05 |
| Шрифты | Подмножества woff2 из Ф1 (`src/ui/fonts/`): Cormorant 600 (preload) + Onest 400. Cormorant только от 20 px. **Для OG-картинки** (`next/og`, Satori не читает woff2) — те же подмножества в TTF или WOFF (`pyftsubset --flavor=woff` или без flavor), отдельные файлы |
| Хранилище файлов | Интерфейс `src/server/storage/` с двумя драйверами по `STORAGE_DRIVER`: `local` (dev и тесты: папка `.data/uploads/` в `.gitignore`, загрузка через подписанный PUT на свой route, отдача через `/api/files/[...key]` с `Range` и `Cache-Control: immutable`) и `s3` (R2 на пилоте, S3 в KZ: presigned PUT/GET, `@aws-sdk/client-s3`). Код приложения знает только интерфейс (план 4.4) |
| Музыка | `createUploadUrl(eventId, kind='music', mime, bytes)` (`requireOwner`; mp3 / m4a / aac ≤ 20 МБ) → загрузка из браузера → `finalizeUpload(assetId)` → обработка `ffmpeg-static`: первые 90 с, MP3 96 кбит/с, затухание 3 с → ~1,1 МБ, ключ с хэшем содержимого. `media_assets.status`: `uploaded → processing → ready / failed`. Обработка синхронная в route с `maxDuration` 60 с. [ПРОВЕРИТЬ на Vercel] размер функции с ffmpeg; запасной путь — без перекодирования при файле ≤ 3 МБ. Права на трек — текст `wizard.music.rights` |
| Ответ гостя | `POST /i/{token}`: обычная форма (303 на `/i/{token}?answered=1`); островок отправляет `fetch` с `Accept: application/json`. Запись — через `withSeating` (Ф4): `actor {kind: 'guest', memberId: null}`, `action: 'answer'`, `record: true`, `summary.from / to`, движок `setRsvp`. `answered_by = 'guest'`, `responded_at`. Лимит 10 в час на токен. После `rsvp_closes_at` (по умолчанию начало дня тоя по Алматы) — состояние «Жауап беру уақыты өтті», POST → 409 |
| Согласие гостя | Галочка `invite.rsvp.consent` (rich text, ссылка на политику) **за флагом** `FEATURE_GUEST_CONSENT` до решения юриста (Р10). Если флаг включён — без галочки отправить нельзя, пишется `rsvp_consent_at` |
| Язык гостя | Видимый ҚАЗ \| РУС (48×48) на конверте и странице; cookie `locale`; `<html lang>`. Без ru-текста приглашения — казахский текст и пометка `invite.*` «есть только на казахском» (Д4/10) |
| Имя семьи и молодых | Имя семьи — в именительном падеже, как ввели (Д4/1); имена молодых — `events.title` как есть; «Той иелері» — только если `hosts_line` не пуст |
| Повторный визит | Если ответ уже дан или cookie «конверт открыт» — сцены нет, сразу приглашение (DESIGN 6.1) |
| Анимации | Только `transform`, `opacity`, `stroke-dashoffset`. Бесконечные — на паузе вне экрана (`IntersectionObserver`) и в фоне. `prefers-reduced-motion`. Режим `html.lite` (без 3D-клапана) включается при `prefers-reduced-motion` или по эвристике слабого устройства (`navigator.hardwareConcurrency ≤ 4` + `deviceMemory ≤ 2`, если доступно) |
| Обложки | В арке SVG-заставка шаблона (5–7 КБ). Когда основатель отберёт ИИ-обложки: `scripts/optimize-covers.ts` (`sharp`, AVIF/WebP, 720×888 ≤ 60 КБ, 1080×1332 ≤ 110 КБ только при ширине ≥ 900), SVG-заставка лежит под картинкой, линия шаңырақа — поверх |
| Заголовки ответа | `Cache-Control: private, no-store`, `X-Robots-Tag: noindex`, `Referrer-Policy: no-referrer`, CSP с nonce для островка. Неизвестный токен → 404 без подробностей, лимит 404 — 30 в минуту на IP |

## 3. Задачи

### 3.1 Страница гостя `/i/{token}`
- [ ] Спайк (день 1) и замер JS / веса (раздел 2).
- [ ] Состояния DESIGN 8.17 для трёх шаблонов («Ақ шаңырақ», «Көк түн» — полная луна, «Қызғалдақ»), на ширинах 320–1440 (поля с декором от 900 px):
  1. конверт;
  2. открытие G5–G12;
  3. приглашение (обложка, имена, текст, дата `Жексенбі · 15 қараша · 18:00`, «Тойға N күн қалды» по Алматы, ресторан + «Картаны ашу», «Той иелері»);
  4. форма ответа;
  5. ответ отправлен;
  6. ответ закрыт;
  7. ошибка сети.
- [ ] MusicToggle: `play()` строго в обработчике «Ашу»; ленивая загрузка после `load` + `requestIdleCallback`; при запрете автовоспроизведения — кнопка «Музыканы қосу»; `aria-pressed`.
- [ ] Ответ без JS (форма) и с JS (`fetch`); изменение ответа до `rsvp_closes_at`; лимиты.
- [ ] `POST /api/i/{token}/ping` (`opened`, `envelope`) через `sendBeacon` → `activity_log` + `families.first_opened_at`.
- [ ] OG-метатеги в `<head>`: заголовок `og.title` с именем семьи, картинка `/i/{token}/opengraph-image`.

### 3.2 OG-картинка

### 3.3 Музыка и хранилище
- [ ] Интерфейс хранилища и драйверы `local` / `s3`; `createUploadUrl`, `finalizeUpload`, обработка ffmpeg, `media_assets`.

### 3.4 Предпросмотр и мелочи из прошлых фаз
- [ ] Настоящий предпросмотр в мастере (Ф3) и в настройках: Server Action отдаёт HTML того же шаблона по черновым данным → `<iframe srcdoc sandbox>` в рамке телефона; «Көру» на шаге шаблона открывает полноэкранный предпросмотр.
- [ ] Мини-конверт «Шақыру қалай барады?» в правой колонке S2 (отклонение 4 ревью Ф4).

### 3.5 Тесты
- [ ] **unit:** тексты и даты (`Intl` с `Asia/Almaty`, «N күн қалды»), `t.rich` без React с экранированием, выбор `lite`.
- [ ] **integration:**
  - ответ гостя через адаптер: версия растёт, запись истории с `actor_kind = 'guest'`, переполнение — предупреждение, рассаженные не двигаются;
  - лимиты (404 по IP, RSVP по токену);
  - после `rsvp_closes_at` → 409;
  - удалённая семья или событие → 404;
  - `finalizeUpload` на локальном драйвере с маленьким mp3 → `ready`, вес ≤ ожидаемого.
- [ ] **e2e** (360, 320, 1440; kk и ru):
  - конверт → «Ашу» → приглашение → ответ → «Рақмет»;
  - **ответ с отключённым JS** (`javaScriptEnabled: false`);
  - изменение ответа;
  - повторный визит без сцены;
  - reduced motion и `lite`;
  - axe; 130 %;
  - бюджет: вес ответа и JS по сетевому журналу Playwright.
- [ ] Lighthouse локально (`@lhci/cli` по собранному standalone) с `budget.json`; в CI — после GitHub.

## 4. Критерии приёмки

1. Страница без React-рантайма: JS ≤ 15 КБ gzip; всё до музыки ≤ 150 КБ; ответ работает без JS.
2. Lighthouse mobile ≥ 90, LCP ≤ 2,5 с (Slow 4G) — локально по standalone; в CI и на preview — после аккаунтов.
3. Три шаблона и все состояния 8.17 совпадают с макетами 05–07 (360 и 1440, kk и ru, 130 %); reduced motion, `lite`, пауза бесконечных анимаций вне экрана.
4. Ответ гостя идёт через адаптер, виден составителю сразу (S1) и в истории; изменение ответа — до `rsvp_closes_at`.
5. Музыка: загрузка, обработка, плеер в мастере и настройках на локальном драйвере; на странице — только по «Ашу», кнопка звука всегда видна.
6. OG-картинка ≤ 300 КБ с именем семьи; метатеги на месте.
7. Предпросмотр в мастере — настоящий шаблон.
8. Тексты только из `content/messages`; никаких склонений имён; все проверки зелёные.
