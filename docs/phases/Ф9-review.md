# Ф9 · Ревью архитектора

Дата: 2026-10-15 · Архитектор · по плану 13.6
Предмет: `docs/phases/Ф9-handover.md`, ветка `phase/F9-budget` (`0df123c` … `945b9de`, от `phase/F7b-hall` `935afef`), 16 скриншотов `docs/phases/F9-screens/` против `Ф9-brief.md` и макета 13.

## Вердикт

**Принято.** Обязательных правок нет. Ниже — решения по отклонениям, одно из них (общие форматтеры) переходит задачей в Ф10. Остались ручная проверка «10 статей за 5 минут» и пара необязательных ключей.

## 1. Что проверено

- Код: `src/server/budget/service.ts` — `budgetView`, `budgetTotals`, `setBudgetTotal`, `setPricePerSeat`, `createExpense` (блокировка события), `updateExpense` (409), `deleteExpense` / `restoreExpense`; `src/domain/budget`.
- Результаты прогонов — по handover: полный последовательный e2e всех фаз **180 passed / 0 failed** на итоговом коде. Два промежуточных прогона с падениями объяснены: тест рамки Ф1 ожидал 404 вместо `#noright`, и локальный PGlite упал посреди прогона.

## 3. Решения по отклонениям

| № | Отклонение | Решение |
|---|---|---|
| 1 | Деньги без `Intl.NumberFormat('kk-KZ')` — в Chrome нет данных казахской локали, группы вручную через неразрывный пробел | **Принято** |
| 2 | Даты форматируются на сервере (в браузерах нет казахских названий месяцев) | **Принято — и делаем правилом для всего приложения.** В Ф10: общий модуль `src/domain/format/` (`formatMoney`, `formatDate` kk / ru с названиями месяцев, `formatDayMonth`, `formatDateTime`, «бүгін / кеше»). Туда переезжают и разрозненные реализации (`domain/invitations/dates.ts`, бюджет, история H7, страница гостя, итоги). Клиент получает готовые строки или вызывает те же функции; `Intl` с `kk` нигде не используется. Unit-тесты на kk / ru |
| 3 | «Бюджеттен асты» = Σ план − бюджет; «Қалды» = бюджет − оплачено (не меньше 0) | **Принято**: перерасход виден заранее |
| 4 | Первая статья «Мейрамхана» становится расчётной автоматически; вторая — обычная | **Принято.** Бейдж «Өзі есептеді» показывает, что сумма считается сама. Если родителям понадобится «аванс ресторану» отдельной строкой, это вторая статья той же категории — работает |
| 5 | 409 — общий `errors.conflict` | Принято |
| 6 | Длинное название — `errors.field.tooLong {max: 80}` | Принято; `budget.item.errors.titleTooLong` не нужен |
| 7 | Строка статьи «Жоспар: … · Төленді: …» вместо мелкой «Төленді» под суммой | Принято временно. **Контент-лиду:** ключ `budget.item.paidLine` («Төленді: {amount}» / «Оплачено: {amount}»), после него — вид макета (мелкая правка, можно в Ф10) |
| 8 | `#noright` → «Басты бетке өту» ведёт на «Қорытынды» события | Принято |
| 9 | «Кто менял» — подпись составителя | Принято |
| 10 | Миры e2e Ф9 отдельным блоком | Принято. При перебазировании на Ф8 оставить оба блока |
| — | Тест рамки Ф1: `/budget` без права → `#noright` вместо 404 | **Принято**: так требует бриф Ф9 |

## 4. Что осталось

- **Ручной замер «10 статей за 5 минут»** (критерий плана) — в протокол РА, вместе с проверкой людьми 50+ (хозяин или родитель семьи-пилота).
- Ключ `budget.item.paidLine` (необязательно).
- CI на Postgres 16 и preview — после аккаунтов.
- **Порядок мержа:** RA → Ф7b → Ф8 → Ф9 (Ф8 у dev1 почти готова). Ф9 перебазируется на `phase/F8-door`, когда Ф8 будет принята; конфликты ожидаются только в мирах e2e.
