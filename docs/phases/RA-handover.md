## Л1 — список гостей без гидратации карточек

**Что сделано** (`src/app/e/[eventId]/guests/`):
- `GuestsScreen.tsx` — теперь **серверный компонент**.
  - Карточки и группы категорий — **одна HTML-строка** (`list-html.tsx`), вставленная через `dangerouslySetInnerHTML`. React их не гидрирует и не кладёт в RSC как элементы.
  - Строка собирается тегированными шаблонами Ф5 с обязательным экранированием (`src/server/invite/html.ts`): разметка и классы те же, что у `GuestCard` / `GroupHead`.
  - Счётчики — серверные кнопки без обработчиков.
- `GuestsIsland.tsx` — единственная гидрируемая часть S1:
  - поле поиска;
  - **один делегированный обработчик** на корне страницы для `data-act` + `data-gid`:
    - `open` — шторка гостя;
    - `send` / `remind` — ссылки wa.me: полный текст собирается при первом касании, фокусе или наведении, клик запускает «Жіберілді ме?»;
    - `filter` — счётчики (`aria-pressed`);
  - поиск и фильтр работают по данным страницы (`data.guests`) и только переключают `hidden` у серверных карточек и групп;
  - строка фильтра, пустые состояния и строка «Жіберілді ме?» на карточке — порталы в пустые серверные слоты;
  - шторка гостя и диалог «Жіберілді ме?» грузятся лениво (`next/dynamic`; шторка — в простое после готовности);
  - `data-ready` на корне означает, что касания работают.
- `list-shared.ts`, `sent-ago.ts` — общие функции без `"use client"`. Попутно исправлено: ссылка-заглушка wa.me убирала из номера букву `D`, а не нецифры (`/D/g` → `/\D/g`).
- Списки других составителей (`?list=`) — та же страница. S5 «Жауап бермегендер» не переделывался (отклонение 2).
- **Тесты:**

  - `guests.spec` «фильтры» считает видимые карточки (`.guest:visible`): отфильтрованные остаются в HTML с `hidden`.
  - Остальные e2e Ф4 (шторка, отправка, «Жіберілді ме?», дубли, axe, 130 %, 48 px) прошли без изменений.

## Л3 — бэкапы (готово к включению)

- `.github/workflows/backup.yml`:
  - ежедневно в 21:30 UTC (02:30 Алматы) + ручной запуск;
  - сначала проверка, что секреты заданы;
  - `pg_dump` 17 из PGDG (не старше сервера Neon 16/17) `--format=custom --no-owner --no-privileges` | `age --encrypt --recipient` → `s3://<бакет бэкапов>/daily/toi-<UTC>.dump.age` (R2 по S3 API);
  - удаление копий старше **30 дней** (и правило жизненного цикла R2, если основатель его включит);
  - секреты: `PROD_DATABASE_URL_UNPOOLED`, `BACKUP_AGE_RECIPIENT` (только открытый ключ), `BACKUP_R2_ENDPOINT` / `_BUCKET` / `_ACCESS_KEY_ID` / `_SECRET_ACCESS_KEY`.
- `scripts/restore.sh <файл> <URL цели> [--identity key.txt] [--compare <URL источника>]`:
  - расшифровка `age`;
  - **отказ**, если в цели уже есть таблицы `public`, и для URL с `prod` / `production`;
  - `pg_restore --no-owner --no-privileges --exit-on-error`;

- **Локальная проверка на настоящем Postgres 17.6** (из скачанного архива, см. «Скачанные инструменты»):
  - источник `toi_src`: миграции + `pnpm db:seed --demo`;
