# Ф2 · Фундамент: база, вход, доступ, i18n — бриф (краткий)

Версия 1.0 · 2026-10-09 · архитектор → разработчик
Статус: **предварительный**. Начинать после вердикта «принято» по Ф0. Архитектор уточнит бриф по итогам Ф0: версии библиотек, результаты SMS.
Оценка: **4,5 рабочих дня** + ревью (по календарю 16–22.10).

## Цель

Получить три вещи:
- рабочую базу по полной схеме;
- вход составителей: по одноразовой ссылке через WhatsApp (основной путь) и по SMS-коду (запасной);
- долгие сессии, проверку прав и сиды из прототипа.

Экраны `/join` и `/login` делаются на временных нейтральных стилях — дизайн v2 приходит в Ф1.

## Источники

- План: раздел 5 (схема, производные значения, доступ), 6.1 (потоки входа 1–4 и таблица действий), 9 (безопасность), 11.2–11.5 (окружения, CI/CD, тесты, сиды).
- `docs/DECISIONS.md`: Р5, Д4/13 (лимит 20), А2, А3.
- `content/CONTENT_REVIEW.md`, раздел 6: ключи `sms.otp`, `auth.*`. Язык SMS = язык интерфейса в момент запроса кода.

## Задачи

- [ ] **Схема Drizzle целиком по разделу 5.**
  - Включить: `login_links`, `allowed_owners`, `member_kind`, `can_manage_budget`, `updated_by`.
  - Число мест гостя: от 1 до 20.
  - Внешний ключ `families → hall_tables` с `on delete set null (table_no)` (нужен PG15+).
  - Миграции только расширяющие; в CI накатываются с нуля.
- [ ] **Деплой прода через `deploy-prod.yml`.**
  - Порядок: `drizzle-kit migrate`, затем `vercel deploy --prebuilt --prod`.
  - Автодеплой `main` в Vercel выключить.
  - Секреты GitHub (`VERCEL_TOKEN`, `DATABASE_URL_UNPOOLED` прода) вносит основатель.
- [ ] **Вход по ссылке (6.1, поток 1).**
  - `issueLoginLink`: 22 символа base62, в базе sha256, срок 72 ч, новая ссылка отзывает старые.
  - `GET /join/{token}` ничего не тратит; тратит только `POST` (`consumeLoginLink`, атомарный `update … returning`).
  - Экран «Сілтеме ескірген».
  - `allowed_owners` и CLI `pnpm admin:owner-link +7…` (поток 4).
- [ ] **Вход по SMS (потоки 2–3).**
  - `requestOtp`: одинаковый ответ для любого номера; SMS отправляется только известным номерам.
  - `otpDeliveryStatus`: опрос через 20 с.
  - `verifyOtp`: 6 цифр, хэш HMAC, срок 5 минут, 5 попыток.
  - Под кнопкой `auth.code.resend` — повтор через запасной провайдер.
  - «Иесінен жаңа сілтеме сұрау» открывает `wa.me` хозяина.
  - `sms_log` хранит маску и хэш номера.
  - Лимиты в `rate_limits`: на номер, на IP, глобальный `SMS_DAILY_LIMIT`.
- [ ] **Сессии.**
  - Cookie `HttpOnly; Secure; SameSite=Lax`, 180 дней со скользящим продлением (продлевать не чаще раза в сутки).
  - Не больше 3 сессий на человека; `device_label`; отзыв сессий.
  - Middleware для `/e/*`.
- [ ] **`authz.ts`.** Функции `requireUser`, `requireMember(eventId, {seating})`, `requireBudget`, `requireOwner`, `guestByToken`, `doorByToken`. Матрица доступа и integration-тесты на 403.
- [ ] **Язык пользователя.** Хранится в `users.locale`, используется для SMS.
- [ ] **Сиды (план 11.5).**
  - Данные: событие «Айбек пен Дана», 3 составителя с правами по типу, 8 категорий, 65 семей `RAW` из `prototype/index.html` (закрепления на столах 7 и 12), зал 4 × 16 × 12, история h1–h6.
  - Данные лежат в **`tests/fixtures/sample-event.ts`** — общий источник для сидов и для золотого теста Ф7a.
  - Демо-номера `+7700000000X` — только для local и preview.
  - Отдельно `seed-empty.ts`.
- [ ] **Реальные телефоны.** Ссылка из WhatsApp открывается, вход сохраняется. Проверить Android Chrome и iOS Safari; записать заметки для подсказок `auth.install.*`.

## Приёмка

- e2e «вход по ссылке» и «вход по коду» (провайдер `console`) зелёные. Проверяется:
  - повторное использование ссылки отклоняется;
  - GET без нажатия «Кіру» ссылку не тратит;
  - просроченная ссылка показывает экран «ескірген».
- Лимиты OTP покрыты тестами. Неизвестный номер получает тот же ответ, а SMS не уходит (проверка по `sms_log`).
- 403-матрица зелёная:
  - «Тек тізім» → рассадка;
  - «Жастар» → расходы;
  - чужой → событие.
- Миграции идут через `deploy-prod.yml`; у preview своя ветка Neon.
- В логах нет ни секретов, ни полных номеров телефонов.
