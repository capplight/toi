### Решения архитектора

| № | Решение | Почему |
|---|---|---|
| **А1** | **Репозиторий = вся папка `d:\My Project\toi\`.** Next.js-приложение лежит в корне, маршруты — в `src/app/`. Документы остаются на местах (`architecture/`, `design/`, `content/`, `research/`, `prototype/`, `docs/`). Тексты читаются напрямую из `content/messages/*.json`, без копий | Один источник правды; ссылки в документах и брифах не ломаются; Vercel собирает из корня без настройки Root Directory |
| **А2** | **Имя проекта Vercel `toi-pilot`** (`toi-pilot.vercel.app`, 20 символов). Если имя занято — другое имя ≤ 9 символов (`toipilot`, `toi-kz`, `toi-app`), домен задаётся переменной `APP_DOMAIN` | SMS-код с WebOTP в 1 сегмент (CONTENT_REVIEW 6.8) |
| **А3** | Вопрос «Жіберілді ме?» после отправки **ссылки входа** составителю **не задаём**. У составителя показываются статусы «Сілтеме жасалды · 72 сағат» → «Кірді · устройство · время» (по `login_links.created_at` / `used_at`). Ключ `send.ask.bodyLoginLink` пока не используется | Факт входа и так виден; лишний вопрос хозяину |
| **А4** | Плитка `summary.tiles.pending` («Жауап жоқ / Нет ответа») **включает** гостей со статусом «Жіберілмеген» — для рассадки и ресторана они считаются по ожидаемому числу мест. Под числом нужна подпись «оның ішінде {n} жіберілмеген / из них не отправлено: {n}». **Контент-лиду: добавить ключ до Ф6** | Совпадает с `design_spec` 5.2 («9 семей, из них 2 не отправлены») |
| **А5** | При расхождении текста в макетах дизайна и в `content/messages` побеждает `content/messages` (пример: чип «2 үстел» в макете, а в текстах «{n} үстел тығыз») | Тексты прошли сверку и финальны (Д5) |
| **А6** (2026-10-11) | **Готовые тексты приглашения не содержат имён.** Имена молодых показываются на приглашении из `events.title`; в тексте — «ұлымыз бен келініміздің» и т. п. Если имена нужны в тексте — только отдельной строкой `{title}` в именительном падеже, без окончаний. Тексты лежат в `content/invitation-presets.json` (владелец — контент-лид). Мастер и сервер не сохраняют текст, в котором остался образец в `[…]` | Окончания падежей, вписанные после имени-образца («[Дана]ның»), неверны для других имён (правило «падежи не строим»); текст получает каждый гость |
