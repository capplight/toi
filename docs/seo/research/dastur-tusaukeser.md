# Тұсаукесер (тұсау кесу) — фактическая база

Страницы: `/kk/dastur/tusaukeser` (2 900), `/ru/traditsii/tusau-keser`. Доступ: 2026-10-25. Реестр `[S#]` — `README.md`.

## Тұсаукесер деген не

- Обряд, который проводят, когда ребёнок начинает ходить (первые шаги, «тәй-тәй басқанда»), чтобы он ходил уверенно и не спотыкался. ✓✓ [S9][S10][S11]
- Название — «разрезание пут». ✓✓ [S10][S18]
- Смысл ала жіп: чтобы ребёнок «ешкімнің ала жібін аттамасын» — был честным (не переступал через договор, «ала жіп»). ✓ [S9]; ала жіп «для честности» ✓ [S10] → ✓✓
- Поверье о вреде без обряда: «қисық табанды болып өсуі мүмкін» [S11] — ✓ один, слабый источник. Не утверждать.

**AIO-определение (своими словами):** Тұсаукесер — баланың алғашқы қадамына арналған дәстүр: тәй-тәй басқан сәбидің аяғына ала жіп байлап, оны сыйлы адам кеседі. Бала өмір жолында сүрінбей, адал жүрсін деген ниетпен жасалады.

## Қай жаста және қашан өткізеді

- Когда ребёнок начинает ходить ✓✓ [S9][S10][S11]. Конкретный возраст в надёжных источниках **не указан**.
- «Около года» — в рефератах (12–14 месяцев) и в обзорах на ru («чаще всего, когда исполняется год»). Не авторитетно.
- **Писать:** «бала тәй-тәй басып, жүре бастағанда (көбіне бір жас шамасында)» — «шамасында» обязательно.

## Ала жіп және тұсауды кім кеседі

- Нить: ала жіп (пёстрая) ✓✓ [S9][S10]; около 1,5 м ✓ [S10]; 2–3 цвета ✓ [S11] (в той же статье — «8 цветов», противоречие).
- Исторически: из тоқ ішек (кишка скота) — к богатству, из көк шөп (трава) — к многочисленному потомству. ✓✓ [S9][S10]; также в рассказе Ж. Абдукаримовой [S14]
- **Кто режет — ⚠ расхождение:**
  - уважаемый человек, которого выбирают родители (родственник или друг семьи), здоровый, с хорошей репутацией ✓✓ [S9][S11]; чаще — старшая, опытная, многодетная женщина [S9];
  - «қағілез, пысық адам» из собравшихся; медлительных не выбирают [S10];
  - для девочки — уважаемая замужняя женщина, для мальчика — уважаемый мужчина [S13].
  - Общее во всех: уважаемый, здоровый, энергичный. **Писать только общее.**
- Чем режут — ⚠: ножом, не ножницами [S9][S11]; «өткір қайшы немесе пышақ» [S10].
- Режущему дарят подарок ✓✓ [S9][S10] (обычно рубашка или обувь [S10] — ✓).

## Тұсаукесер тәртібі: қадам бойынша

Подтверждённые шаги (порядок по S9/S10/S11):
1. Назначают день, зовут гостей ✓ [S10]
2. Расстилают белую ткань / ковёр (ақ жол) ✓✓ [S9][S11]
3. Ноги ребёнка связывают ала жіп ✓✓ [S9][S10][S11]
4. Уважаемый человек разрезает нить, произносит пожелания ✓✓ [S9][S11]
5. Двое ведут ребёнка за руки по ақ жол ✓✓ [S9][S10]; [S13] — «пару шагов, затем отпускают»
6. Шашу ✓✓ [S9][S11][S13]
7. Подарок тому, кто резал ✓✓ [S9][S10]

Дополнительно:
- **Предметы в конце дорожки** (современная форма): деньги (будет богат), камчы (будет вести людей), книга (будет мудрым) ✓✓ [S9][S11]; S11 добавляет музыкальный инструмент, инструменты. Ребёнок выбирает предмет. «Раньше впереди стояла мать с раскрытыми руками, сейчас — предметы» ✓ [S9]
- Бег детей наперегонки, победитель развязывает нить и получает приз и сладости ✓ [S10] — один источник, писать «кей өңірлерде».
- Во время вождения поют «Тұсаукесер» әні ✓ [S10]; крики «Жүйрік бол!», «Шауып кет!» ✓ [S10]

## Не дайындау керек

| Пункт | Подтверждение |

| ала жіп (~1,5 м) | ✓✓ [S9][S10] |
| пышақ (кейде қайшы) | ✓✓/⚠ [S9][S10][S11] |
| ақ мата / кілем (ақ жол) | ✓✓ [S9][S11] |
| шашу: құрт, май, кәмпит, ойыншық, асық, сылдырмақ | ✓ [S10] (шашу как таковой — ✓✓) |
| ет, шай, дастархан | ✓ [S10] |
| подарок тұсау кесушіге | ✓✓ [S9][S10] |
| предметы для выбора: ақша, қамшы, кітап | ✓✓ [S9][S11] |
| национальная одежда ребёнку | ✓ [S11] |

Дома, если гостей мало; летом — на даче, во дворе, в доме отдыха ✓ [S11].

## Тұсаукесер жыры

- Песня/жыр существует, исполняется при обряде ✓✓ [S9][S10]; относится к тұрмыс-салт жырлары вместе с шілдехана, бесік жыры (рефераты — не подтверждение).
- Широко известен народный «Қаз-қаз балам…» — **текст онлайн не верифицирован**, варианты различаются. Статус — народный (автор не указан ни в одном источнике).
- **Рекомендация:** H2 «Тұсаукесер жыры (народный вариант)» — только из сборника через О8. Иначе заменить на «Тұсау кесерде айтылатын тілек» (формулы «Жүйрік бол!», «Шауып кет!»).

## Современная практика, споры

- Тұсаукесер со звёздами за деньги: гонорары от ~300 тыс. до 3 млн ₸ (агенты и исполнители, июль 2023) ✓ [S12]. Звезда турецких сериалов — $200 000 (finratings, по выдаче) — не проверено.
- Этнограф Таттігүл Қартаева: традиционно за тұсау денег не брали, его резали уважаемые старшие, а не певцы и блогеры; «Тұсаукесер қазіргі кезде — трансформацияға ұшыраған дәстүрдің бірі» ✓ [S12]
- Депутат Дәулет Мұқаев бесплатно, ~2 500 детей с 2015 ✓ [S12]
- Обряд «тұсаукесер для автомобиля» вызвал возмущение (azattyq-ruhy, по выдаче) — не проверено, не использовать.

## FAQ

1. **Тұсаукесер қай жаста жасалады?** — бала жүре бастағанда; нақты жас дереккөздерде көрсетілмейді, көбіне бір жас шамасы.
2. **Тұсауды кім кеседі?** — ата-ана таңдаған сыйлы, дені сау, пысық адам [S9][S10][S11].
3. **Ала жіп нені білдіреді?** — адалдықты: «ешкімнің ала жібін аттамасын» [S9][S10].
4. **Тұсауды қайшымен кесуге бола ма?** — дереккөздер әртүрлі: көбі пышақпен дейді [S9][S11], кейбірі қайшыны да атайды [S10].
5. **Тұсау кесушіге не сыйлайды?** — сыйлық (көбіне көйлек не аяқкиім) [S9][S10].
6. **Тұсау кесуге ақша төлеу керек пе?** — дәстүрде жоқ (этнограф Т. Қартаева, S12).
7. (ru) **Тусау кесер что это?**

## Что НЕ утверждать

- Точный возраст («ровно в 1 год»).
- Что резать ножницами запрещено.
- Пол режущего как правило.
- «Без обряда ребёнок вырастет косолапым».
- Текст «Қаз-қаз балам» без сборника.
- Перечень «что значит каждый предмет» сверх подтверждённых трёх (деньги, камчы, книга).
