# Қыз ұзату — фактическая база

Страницы: `/kk/dastur/qyz-uzatu` (1 680), `/ru/traditsii/kyz-uzatu` (350). Доступ: 2026-10-25. Реестр — `README.md`.

## Қыз ұзату деген не

- Проводы невесты из родительского дома в семью жениха; той устраивает сторона невесты. ✓✓ [S6][S20][S19]
- Организует и оплачивает сторона невесты, инициаторы — её родители. ✓ [S20]; стороны часто проводят отдельные тои (қыз ұзату у невесты, үйлену той у жениха) — bcc.kz в `research/toi_pains_research.md` → ✓✓
- Символ союза двух родов / семей и начала нового очага (отау) с бата перед людьми. ✓✓ [S19][S20]

**AIO-определение:** Қыз ұзату — қалыңдықтың әке-шешесі қызын күйеу жағына аттандыратын той. Қыз туған үйімен, туыстарымен қоштасады, ата-анасы ақ батасын береді.

## Құдалықтан ұзатуға дейін: кезеңдер

Подтверждённые этапы свадебного цикла (порядок общий, без жёстких дат):
1. Құда түсу / құдалық ✓✓ [S6][S24][S25] → `dastur-qudalyq.md`
2. Сырға салу ✓✓ [S6][S16] → `dastur-syrga-salu.md`
3. Қалың мал (выкуп; сегодня в основном на юге и деньгами, больше «поддержка», чем выкуп) ✓✓ [S6][S19]; на севере «ана сүті» вместо калыма ✓ [S7]
4. Қыз ұзату ✓✓
5. Үйлену той, беташар у стороны жениха ✓✓ [S6][S3]

- Место и время қыз ұзату оговаривают на құдалық; удобным считают проводить **за неделю до свадьбы** ✓ [S20] (одно издание — писать «көбіне», не как правило).
- Перед ұзату родственница невесты (жеңге) ездит знакомиться с условиями жизни в семье жениха («қыз танысу») ✓ [S19] — один источник.

## Той тәртібі (как проходит)

⚠ Источников о «программе вечера по часам» **нет** — это практика ведущего (асаба), а не традиция. Предложение: H2 переименовать в «Қазіргі қыз ұзату кеші қалай өтеді» и давать как практику.

Подтверждённые элементы:
- Прощание невесты с домом и родными ✓✓ [S6][S19][S22]
- Белая дорожка «ақ жол» перед невестой ✓ [S6]
- Прощальная песня: **сыңсу** (қоштасу әні) ✓✓ [S19][S22][S6]. Поют сёстры или жеңгелер, обходя с невестой дома; сегодня — в основном при прощании, когда невесту увозят ✓ [S22]. В S19 — мать провожает сыңсу.
- **Жар-жар** — песня-диалог группы жениха (весёлый тон) и подруг/родственниц невесты (грустный тон) перед уходом невесты ✓ [S21]; в рефератах тоже. Рефрены в регионах: «үкі-ау», «ай-ау» ✓ [S21]
- **Тойбастар** — песня на тое (по S23 — в последний день, на прощальном вечере молодёжи) ✓ [S23] ⚠ см. README
- «Невесте нельзя оглядываться назад» ✓ [S6] — один источник, писать как поверье.
- Традиционно уезжает на рассвете — рефераты; **не утверждать**.
- Никах (неке) по мусульманскому обычаю проводит молда в ауле невесты ✓ [S19] — один источник; сейчас время и место неке различаются (см. `dastur-uilenu-toi.md`).

## Кімдерді шақырады: туыстар, құдалар, нағашылар

- Со стороны жениха — ближайшие родственники, в основном старшие; обычно тот же круг, что ездил на құдалық; делегация ~10–15 человек, присутствует от начала до конца ✓ [S20]
- Дальних родственников и друзей жениха зовут уже на свадьбу ✓ [S20]
- Жених «ждёт в конце пути» ✓ [S6]; в S20 жених — среди получающих/дарящих подарки — ⚠ данные о присутствии жениха неоднозначны.
- Остальной состав (нағашылар, родня по отцу, соседи, коллеги) — источников о «правилах» нет; это обычная практика, без нормы.

## Құдаларды қалай күтеді және қайда отырғызады

- От жениха подарки получают женщины со стороны невесты, участвующие в обряде ✓ [S20]
- Для гостей готовят небольшие подарки, которые S20 называет «тойбастар» ✓ [S20] (см. README — бытовое значение слова)
- О месте сватов за столом в зале — нет данных; традиционный принцип: на первом приёме сватов (құда шақырыс) на төр сидит старший из сватов ✓ [S39] → `rassadka.md`

## Қыздың жасауы, киіт

- **Жасау** (приданое): постель (көрпе-төсек), одежда, ковры, украшения ✓ [S19]; сегодня — украшения, одежда, мебель, техника ✓ [S6] → ✓✓
- Исторически жасау — не личная собственность девушки, а её «духовное и материальное наследие», которое она несёт в новую семью ✓ (informburo, «Жасаусыз қыз — тамырсыз гүл», по выдаче)
- **Киіт** — взаимные подарки двух семей после сватовства; бас киіт старшему свату, аяқ киіт остальным; «не продажа дочери» ✓ [S26] (эксперт); киіт родителям невесты — ✓ [S15] → ✓✓ → подробно `dastur-qudalyq.md`
- **Одежда невесты** на ұзату: часто национальный наряд (көйлек с длинными рукавами и др.) ✓ (nur.kz «казахские платья на кыз узату», по выдаче); мать в сәукеле на проводах ✓ [S19]

## FAQ

1. **Қыз ұзатуды кім жасайды?** — қыздың ата-анасы [S20].
2. **Қыз ұзату мен үйлену тойының айырмашылығы?** — ұзату — қыз жағында, үйлену той — күйеу жағында [S6][S20].
3. **Қыз ұзату тойына күйеу жақтан кімдер келеді?** — жақын, көбіне жасы үлкен туыстар, 10–15 адам [S20].
4. **Сыңсу деген не?** [S22]
5. **Жар-жар қашан айтылады?** [S21]
6. (ru) **Кыз узату что это** (260) / **как проходит** / **сценарий кыз узату** (ответ: строгого сценария в традиции нет; описать элементы).
7. **Кыз узату за сколько до свадьбы?** — часто за неделю [S20] (не правило).

## Что НЕ утверждать

- «Сценарий по часам» как традицию.
- «Невеста уезжает на рассвете» как обязательное.
- «Год не может вернуться домой» (реферат).
- Что жених обязательно присутствует / не присутствует.
- Размеры қалың мал, ана сүті.
- Что «қыз алып қашу» — традиция: этнограф Болат Бопайұлы: «қазақта "қыз алып қашу" деген дәстүр де, ғұрып та, салт та, ырым да жоқ» (tengrinews, по выдаче) — можно использовать в FAQ после чтения статьи.
