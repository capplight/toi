# Мерейтойға тілек: 50 жас, 70 жас, 60/80 — фактическая база

Страницы: `/kk/tilekter/50-jas` (1 900), `/kk/tilekter/70-jas` (720), `/kk/tilekter/mereitoi` (140). Доступ: 2026-10-25. Реестр — `README.md`.

## Что известно о возрастах в традиции

- **Мүшел** — 12-летний цикл; мүшел жас: 13, 25, 37, 49, 61, 73, 85, 97 ✓✓ [S36][S37][S49]
- После мүшел человек раздаёт свою любимую одежду ✓ [S37]; сегодня отмечают «мүшелтой» ✓ [S50] (по выдаче)
- Новый мүшел начинается не в день рождения, а с начала следующего года ✓ [S49] (inform.kz, по выдаче)
- **50 жас:** «ел ағасы» — наставник младших: «Кейінгі ұрпаққа жөн сілтеп, ақылшы болған» ✓ [S37] (один источник)
- **60 жас:** «отағасы», «пайғамбар жасы» ✓ [S37] ⚠ (63 — возраст Пророка по хадисам; той на 63 как казахская традиция не подтверждён)
- **70–80:** «қарасақал, ақсақал деп құрмет тұтқан» ✓ [S37]; ⚠ ақсақал «с 73» [S49]
- **Юбилей 50/70 как традиционный той — источников нет.** Празднование юбилеев по круглым датам — современная практика. Мүшел (49, 61, 73) — традиционная.
- Мүшел 49: по e-history — «мысли и ум на пике» ✓ [S36]; 61 — «мудрость растёт»; 73 — «начало старости» ✓ [S36][S37]

## Что принято желать (подтверждённые образы)

| Возраст | Образы | Основание |
|---|---|---|
| 50 | ел ағасы, ақылшы, жөн сілтеуші; бірақ көп сөйлеуге болмайды | [S37] |
| 60 | отағасы | [S37] |
| 70 | ақсақал, қадірлі, ұрпақ, бата беруші | [S37][S35 — бата дают старшие] |
| общее | «Өмір-жасың ұзақ болсын», «Мереке мерекеге ұлассын» | [S34] |

- Для 70 жас — важный поворот: юбиляр сам обычно **даёт** бата (он старший). Тілек от младших — уважительный, без «наставлений». (Вывод из S34/S35.)

## Что НЕ утверждать

- «50 жас — мүшел» (мүшел — 49).
- «63 жас — пайғамбар жасы тойы» как казахская традиция.
- Конкретный возраст «ақсақал».
- «Мерейтой — древний обычай».
