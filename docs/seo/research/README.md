## 2. Методика

1. Поиск на kk и ru (WebSearch), затем чтение страниц (WebFetch). Дата доступа для всех источников — **2026-10-25**.
2. Приоритет источников: UNESCO → энциклопедии (через kk.wikipedia, только если у статьи есть ссылки на «Қазақстан: Ұлттық энциклопедия», «Қазақ әдебиеті. Энциклопедиялық анықтамалық», «Қазақ мәдениеті») → материалы СМИ с названным этнографом (informburo, tengrinews, nur.kz, inbusiness) → СМИ без эксперта (weproject) → прочее.
3. **Не считаются подтверждением:** stud.kz, infourok, рефераты, сайты поздравлений, объявления Kaspi/OLX (кроме вопросов рынка). Они могли быть использованы только как подсказка, где искать.
4. «Независимые» = разные издания. Две статьи informburo — это один источник для правила «двух источников», если они не ссылаются на разных экспертов.
5. Инструмент чтения страниц не выдаёт длинные цитаты (тексты песен, жыров). Поэтому **полных текстов беташар жыры, тұсаукесер жыры, сыңсу, жар-жар в этой папке нет** — есть ссылки и правовой статус. Это совпадает с правилом авторского права ниже: полный текст писатель берёт из печатного сборника, а специалист (О8) проверяет.
6. Сайты Института литературы и искусства им. Ауэзова, Института истории и этнологии, qazaqstantarihy.kz, e-history.kz (кроме одной заметки о мүшел) в поиске по нашим темам не дали страниц с описанием обрядов. Это пробел: рекомендуется заказать проверку у специалиста О8 по печатным изданиям (Кенжеахметұлы С. «Қазақтың салт-дәстүрлері мен әдет-ғұрыптары», 1994; «Жеті қазына»; «Қазақстан: Ұлттық энциклопедия», 1998; серия «Бабалар сөзі»).

## 5. Правила использования текстов (авторское право)

Основание: Закон РК «Об авторском праве и смежных правах», ред. на 20.08.2026 [S42].
- **Ст. 8 п. 3:** «произведения народного творчества» не являются объектами авторского права. Народные бата, жыр, мақал можно цитировать полностью, с пометкой «халық аузынан». **Но** конкретная запись или обработка фольклора в сборнике или на сайте может быть авторской (составитель, переводчик). Безопасный путь — брать из академического сборника и указывать сборник.
- **Ст. 28 п. 1:** срок охраны — вся жизнь автора и **70 лет** после смерти.
- **Ст. 28 п. 7:** если автор **репрессирован и реабилитирован посмертно**, срок начинается с 1 января года, следующего за годом реабилитации.
  - **Пример, важный для беташар:** Ілияс Жансүгіров (ум. 1938, реабилитирован в 1957 [S43]) — его «Беташар» охраняется **до 31.12.2027**. В переходный период в контент **не включать** его текст полностью; ссылка и пересказ — можно. С 01.01.2028 — общественное достояние. [Расчёт по ст. 28 п. 7; юристу подтвердить.]
  - Абай (ум. 1904), Біржан сал (ум. 1897) — общественное достояние.
- **Википедия (CC BY-SA 4.0):** текст статей kk.wikipedia копировать нельзя без указания авторства и той же лицензии на нашу страницу. Используем только факты своими словами и короткие формулы.
- **Подборки тілек на сайтах поздравлений** — по умолчанию авторские. В эту папку они **не переносились**. Писатели пишут свои тексты по образам и формулам из файлов `tilek-*.md`.
- Короткие устойчивые формулы («Құдалық қабыл болсын», «Дастарқаның тоқ болсын», «Батамен ер көгереді…») — народные формулы и пословицы, их можно использовать.
