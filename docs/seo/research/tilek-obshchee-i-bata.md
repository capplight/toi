# Тілек и бата: общая база (хаб, ақ бата, ru-поздравления)

Страницы: `/kk/tilekter` (3 600), `/kk/tilekter/bata` (840), `/ru/pozdravleniya-na-kazakhskom` (150). Доступ: 2026-10-25. Реестр — `README.md`.

## 1. Тілек и бата: в чём разница

- **Бата** — устойчивый малый жанр казахского фольклора: короткое ритмичное рифмованное благопожелание на устойчивых образах ✓✓ [S33][S35]
- Виды по смыслу: **ақ (оң) бата / алғыс** и **теріс бата / қарғыс** ✓✓ [S33][S34] (+ Шортанбаев, КазНУ 2020, по выдаче)
- **Тілек** — пожелание вообще; бата — его ритуальная форма от старшего. Т. Әлібек: женщина бата не даёт, «Әйел адам тек ақ тілегін айтқан» ✓ [S35] (одно мнение; ⚠ на практике женщины говорят пожелания на тоях).
- Пословица: «Батамен ер көгереді, жаңбырмен жер көгереді» ✓ [S33] (народная — можно использовать)

## 2. Кто даёт бата

- Обычно уважаемые старшие (ақсақалдар, көпті көрген қариялар), батагөй ✓✓ [S33][S34][S35]
- За дастарханом — старший и самый уважаемый гость ✓ [S34]
- Бата давали и известные люди (пример: Шакир Әбенов — Назарбаеву, 1991) ✓ [S35]

## 3. Как произносят и слушают

- Все поднимают ладони (қол жайып), не перебивают до конца, затем проводят ладонями по лицу ✓✓ [S33 — «қол жайып»][S34 — «қос алақанымен бетін сипайды»]
- На юге и западе молодёжь при бата за едой стоит с раскрытыми ладонями ✓ [S35]
- Получивший бата гость традиционно благодарит и дарит (ткань, скот) ✓ [S35]
- «Әумин» — в наших источниках **не упомянут**. Можно писать только как общеизвестное «әумин» после проверки О8.

## 4. Структура (для H2 «1 минуттық құрылым»)

- Научного описания «вступление — тело — концовка» в прочитанных источниках **нет**.
- Подтверждено: бата коротка, ритмична, рифмована, на устойчивых образах; содержание зависит от повода ✓✓ [S33][S35]
- Грамматика пожеланий видна в народных образцах: формы на **-сын/-сін** («берсін», «болсын»). Это наблюдение по текстам S33/S34/S16, не цитата из исследования.
- **Мнение исследователей:** бата должна идти от сердца, своими словами; «жаттап алған бата біреудің батасы болып есептеледі» ✓ [S35] (этнограф С. Негимов, Т. Әлібек). → Хороший аргумент для страницы: «наши тексты — образцы, скажите своими словами».
- **Предложение по H2 «Тойда тілекті қалай айту керек»:** не выдумывать «4 шага» как традицию. Писать как практический совет от редакции (сәлем → кімнен → тілек → бата), явно как совет, а не обычай.
- **H2 «Тойда сөз сөйлеу әдебі: кім бірінші, қанша уақыт»:** порядка выступлений в источниках нет. Есть: этнограф и автор S5 советуют вместо длинных тілек брать бата у 1–2 старших ✓ [S5]. Предлагаю переименовать в «Тойда тілек айту әдебі» без «кім бірінші».

## 5. Поводы бата (что ищут и что подтверждено)

Виды бата по поводу: нәрестеге, ұлға, қызға, келінге, жолаушыға, жастарға, сүндет тойы, наурыз, ораза айт, жарапазан, ас қайыру ✓ [S34]; чаще всего — при рождении ребёнка, бесікке салу, в дорогу, келін түсіру, ас қайыру ✓ [S34]. Ситуационные бата у дастархана, на празднике, путнику ✓ [S33] → ✓✓

## 6. Народные формулы (можно использовать, «халық аузынан»)

Все — короткие устойчивые формулы из источников, где они даны как народные образцы. Права: фольклор (ст. 8 п. 3 [S42]).

| Формула | Повод | Источник |
|---|---|---|
| «Дастарқандарыңа береке берсін, / Бастарыңа мереке берсін.» | ас батасы, той | [S33] |
| «Дастарқаның тоқ болсын, / Уайым-қайғың жоқ болсын!» | ас батасы | [S33] |
| «Ғұмыр берсін жастарыңа!» | жастарға | [S33] |
| «Өмір-жасың ұзақ болсын» | алғыс бата | [S34] |
| «Мереке мерекеге ұлассын» | мереке | [S34] |
| «Ұлыс оң болсын. Ақ мол болсын» | Наурыз | [S34] |
| «Құдалық қабыл болсын» | құдалық, сырға салу | [S16] |
| «Құда мың жылдық, күйеу жүз жылдық» | құдалар (мақал) | [S26] |
| «Жүйрік бол!», «Шауып кет!» | тұсаукесер | [S10] |
| «Баланың мойны берік болсын» | шілдехана | [S30] |
| «Батамен ер көгереді, жаңбырмен жер көгереді» | о бата (мақал) | [S33] |

**Не найдено с подтверждением:** полные народные бата для жастарға, қыз ұзату, сүндет той, мерейтой. Популярные «Қосағыңмен қоса ағарыңдар», «Ұзағынан сүйіндірсін» — поиск источника с атрибуцией не дал результата. Это общеупотребительные формулы речи, их можно использовать как отдельные слова/выражения, но не как «народную бата» с пометкой «халық аузынан» без сборника.

## 7. Классики (общественное достояние)

- Абай (ум. 1904), Біржан сал (ум. 1897) — свободны. Текстов про тілек/бата в этой работе не собрано.
- Жанқұтты шешеннің Абайға берген батасы — упоминается в школьных материалах (выдача); источник текста — проверить в сборнике.
- **Не использовать как свободные:** Ілияс Жансүгіров (охрана до 31.12.2027, ст. 28 п. 7 [S42][S43]), любые акыны XX–XXI вв.

## FAQ (хаб)

1. **Ақ бата деген не?** [S33]
2. **Батаны кім береді?** [S34][S35]
3. **Әйел адам бата бере ме?** — пікір: дәстүрде әйел ақ тілек айтады (Т. Әлібек) [S35].
4. **Бата бергенде не істейді?** — қол жайып тыңдайды, соңында бетті сипайды [S34].
5. **Жаттап алған батаны айтуға бола ма?** — зерттеушілер өз сөзіңізбен айтуды ұсынады [S35].

## Что НЕ утверждать

- «Традиционный порядок тостов на тое».
- «Структура бата из 4 частей» как научный факт.
- Любой текст как «народный» без сборника.
