# Жастарға тілек (үйлену тойы) и келінге тілек — фактическая база

Страницы: `/kk/tilekter/uilenu-toi` (1 810), `/kk/tilekter/kelinge` (600). Доступ: 2026-10-25. Реестр — `README.md`.

## Жастарға (жас жұбайларға) тілек

- Бата «жастарға» — отдельный распространённый вид ✓ [S34]; «Ғұмыр берсін жастарыңа!» ✓ [S33]
- Современные бата желают молодым жизни, счастья, успеха; дому — мира и достатка ✓ [S33]
- Смысл свадьбы — создание нового очага (отау, шаңырақ), союз двух родов ✓✓ [S19][S20]
- Образы, подтверждённые контекстом: шаңырақ / отау [S19]; береке, дастарқан [S33]; ұзақ ғұмыр [S33][S34]; құда-жекжат, екі әулет [S19][S26].
- «Қосағыңмен қоса ағар», «Ұзағынан сүйіндірсін» — общеупотребительные формулы; источника-сборника не найдено (см. хаб §6). Использовать как живую речь, не как «халық батасы».

## Келінге тілек

Опора — беташар (см. `dastur-betashar.md`):
- В конце беташар — ақ тілек келін ✓ [S4]; после чая — бата старших ✓ [S3]
- Темы наставлений в беташар жыры: уважать свёкра и свекровь, говорить мягко, не смотреть дерзко на старших, хранить честь семьи ✓✓ [S3][S4]
- Образы: келін — новый член семьи, «шаңыраққа жаңа түскен келін» ✓ [S3]; свекровь целует в лоб ✓✓ [S4][S5]; на юге — красный халат как знак новой келін [S7]
- Бата «келінге» — отдельный вид; келін түсіру — один из самых частых поводов для бата ✓ [S34]

## Кто говорит

- Бата — ақсақал, ата (старшие) ✓✓; ене и апалар — ақ тілек ✓ [S35]
- Достар — тілек, не бата (по логике S35; правила нет).

## Тексты

Народных текстов с атрибуцией не найдено. Всё пишется заново. Наставительный тон беташар — подтверждённый мотив для «келінге» ✓✓.

## Что НЕ утверждать

- Что «келінге тілек айтатын кезек» существует в определённом порядке.
- Цитаты из беташара Жансүгірова (охрана до 2028).
