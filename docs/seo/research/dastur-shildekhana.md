# Шілдехана — фактическая база

Страница: `/kk/dastur/shildekhana` (1 000). Доступ: 2026-10-25. Реестр — `README.md`.

**Предупреждение:** почти все факты — из одного источника (kk.wikipedia со ссылкой на Ұлттық энциклопедия 1998 [S30]). Вторые источники — рефераты. Страницу писать осторожно или после О8.

## Шілдехана деген не

- Вечер в честь новорождённого; другое название — «шілде күзет» (охрана младенца). ✓ [S30]; «бала туған күні кешке ауыл жастары жиналады, кейде үш күнге дейін созылады» — также в материалах выдачи (реферат) → ✓
- Цель — защитить мать и ребёнка от сглаза и злых духов; первые 40 дней считались опасными ✓ [S30]; «первые 40 дней — опасный период» также [S13] → ✓✓
- Слово связывают с персидским «чилле» — «сорок» ✓ [S30]
- Со временем шілдехана превратилась в «ұлттық ойын-сауық кеші» ✓ [S30]

## Қашан және кім

- Вечером в день родов, иногда до трёх дней ✓ [S30] (+ реферат)
- Собирается молодёжь аула; родня, соседи, знакомые приходят с пожеланиями и шашу ✓ [S30]
- «В охране участвуют только молодые, старшие не приходят» ✓ [S30] — один источник.
- Сүйінші: вестники; мальчика объявляли «ат ұстар», «жылқышы», девочку — «көйлек тігер», «сауыншы» ✓ [S30]

## Тәртібі

- Песни, күй до рассвета, айтыс, игры ✓ [S30]
- Режут скот, накрывают дастархан ✓ [S30]
- Матери дают шейный позвонок (мойын омыртқа), едят без ножа, кость вешают высоко: «Баланың мойны берік болсын» ✓ [S30]
- Тыштыма/тыштырма — бабушка пропускает сладости через отверстие бесіка ✓ [S30] (см. `dastur-besik-toi.md`)
- Лампа/огонь горит до трёх дней [S30]; до 40 дней у бесіка [S29] → ✓✓ (в разных формах)

## Шілдехана жыры

- Жанр есть (тұрмыс-салт жырлары) — рефераты; текста нет. Не публиковать без сборника.

## Что НЕ утверждать

- Конкретные «обязательные» блюда, кроме мойын омыртқа.
- «Старшим нельзя приходить» как правило.
- Тексты жыра.
