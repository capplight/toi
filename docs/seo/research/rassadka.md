# Рассадка гостей (отырғызу) — фактическая база

Страницы: `/ru/rassadka-gostei` (510), `/kk/otyrgyzu-jospary`, термин «төр» в сөздік. Доступ: 2026-10-25. Реестр — `README.md`.

## Главный вывод

Традиционные правила описаны **для дома / юрты и приёма гостей**, а не для банкетного зала с круглыми столами. Правила зала (стол молодых, столы сватов) — современная практика, источников нет. На странице явно разделять: «дәстүр» и «бүгінгі практика».

## Төр

- Самое почётное место — напротив входа ✓✓✓ [S38][S39][S40]
- Для старших и уважаемых гостей ✓✓ [S38][S39]; приглашают словами «төрлетіңіз», «төрге шығыңыз» ✓ [S38]
- Мақалдар: «Есіктен кіріп, төр менікі деме»; «Төрдегі күлсе, есіктегі жымияды» ✓ [S38] (народные — можно использовать)

## Принципы рассадки (традиция)

- «Жасына қарап отырып, жағына қарап сөйлейтін халықпыз» — сидят по возрасту, говорят по красноречию ✓ [S39]
- Старший по возрасту не всегда самый почётный ✓ [S39]
- На первом приёме новых сватов (құда шақырыс) на төр садится старший из сватов; родня хозяев — ниже, независимо от возраста ✓ [S39]
- Гостя издалека сажают на төр независимо от возраста: «Алыстан алты жасар бала келсе, алпыстағы шал барып сәлем береді» ✓ [S39]
- Нағашы почитаются выше родни по отцу ✓ [S39] (один автор; объяснение — его предположение). ⚠ Не делать из этого «правило рассадки».
- Құда (зять) и родня жены: «как құда сидит выше күйеу бала» — семейные примеры автора ✓ [S39]
- Споры за места исторически доходили до вражды ✓ [S39]; Мухтар Ауэзов сел на свободное место: «почётное место там, где я сижу» (анекдот) ✓ [S39]
- Казахские женщины сидят за одним дастарханом с мужчинами ✓ [S39]
- Регионы различаются в мелочах ✓ [S39]
- Сыбаға — части мяса по рангу и возрасту; ошибка = оскорбление ✓✓ [S25] + informburo «сыбаға» (по выдаче)

## Современная практика (не традиция)

- Круглые столы на 10–12 мест; стол диаметром 1,5 м — 10–11 человек ✓ (объявления Kaspi, наш ресёрч 2.3)
- В дорогих залах Алматы — поимённая рассадка с планом на входе ✓ (digitalbusiness 2026, ресёрч)
- Офлайн-услуги «план рассадки и номерки» ✓ (vipcards.kz, all.biz, ресёрч)
- Стол молодых на төр, столы сватов ближе к төру — **источников нет**. Подавать как «әдетте» / «обычно делают так» и как настройку продукта.
- Совет этнографа не сажать молодых на «трон» (особое возвышение) ✓ [S5]

## Ответы на PAA (что можно сказать)

| Вопрос | Ответ по фактам |
|---|---|
| Кто сидит за столом молодожёнов? | Нет традиционной нормы для зала; обычно молодые и их друзья (күйеу жолдас, құрбылар) — **без источника**, писать как практику |
| Где сидят сваты? | Традиционно старший сват — на төр (на приёме сватов) [S39]; в зале — ближе к төру (практика) |
| Где сидят нағашы? | Почётные гости; одно мнение, что почётнее родни по отцу [S39] |
| Кто сидит на төре? | Старшие и почётные гости [S38][S39][S40]; гость издалека [S39] |

## Что НЕ утверждать

- «6 правил рассадки на казахском тое» как традиционный свод (такого свода нет). Предложение: H2 «6 правил» → «Рассадка на тое: что говорит традиция и как делают сегодня».
- «Молодые по традиции сидят на төре».
- «Нағашы всегда выше сватов» / наоборот.
- Поимённая рассадка как норма (на 300–600 гостей чаще группы → столы; ресёрч 2.3 — вывод, не факт).
