# Бесік тойға тілек (и тілек для тұсаукесер, шілдехана) — фактическая база

Страница: `/kk/tilekter/besik-toi` (1 300); разделы тілек в `/kk/dastur/tusaukeser`, `/kk/dastur/shildekhana`. Доступ: 2026-10-25. Реестр — `README.md`.

## Бесік той

- Бата при рождении ребёнка и бесікке салу — самые частые поводы бата ✓ [S34]
- Подтверждённые мотивы обряда: спокойный сон (окуривание адыраспан — слабый источник), сладкая жизнь (тыштыма: сладости через бесік) ✓✓ [S28][S29][S13], защита первых 40 дней ✓✓ [S30][S13], нағашы приносят бесік ✓✓ [S28][S13][S29]
- Кто говорит: әже (кладёт ребёнка) ✓✓ [S29][S13], нағашылар, ақсақал — бата.
- Образы: бесік, шаңырақ, ұйқысы тыныш болсын, тәтті өмір, ата-ананың қуанышы — последние два без источника (редакторские).

## Тұсаукесер

- Подтверждённые пожелания: «Жүйрік бол!», «Шауып кет!» ✓ [S10]
- Мотивы: ақ жол, сүрінбей жүру, адал болу (ала жіп) ✓✓ [S9][S10][S11]; предметы: ақша — бай, қамшы — ел басқарады, кітап — білімді ✓✓ [S9][S11]
- Отдельного спроса «тұсаукесерге тілек» — 0 (план), раздел внутри статьи.

## Шілдехана

- «Баланың мойны берік болсын» ✓ [S30]
- Сүйінші-формулы: ұл — «ат ұстар», «жылқышы»; қыз — «көйлек тігер», «сауыншы» ✓ [S30]

## Что НЕ утверждать

- Тексты бесік жыры / тұсаукесер жыры без сборника.
- «Ырым» вокруг предметов сверх подтверждённых.
