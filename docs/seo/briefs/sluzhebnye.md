## 1. FAQ — `/kk/suraqtar`, `/ru/voprosy`

- **Title kk:** Сұрақтар: шақыру, тізім, отырғызу
- **Description kk:** {BRAND} туралы жиі қойылатын сұрақтар: шақыруды қалай жіберу, тізімді бірге толтыру, жауаптар, отырғызу, кіреберістегі көмекші, деректердің қауіпсіздігі.
- **H1 kk:** Жиі қойылатын сұрақтар
- **Title ru:** Вопросы о приглашении, списке гостей и рассадке
- **Description ru:** Частые вопросы о {BRAND}: как отправить приглашение, вести список вместе с родителями, собрать ответы, рассадить гостей и встретить их на входе.
- **H1 ru:** Частые вопросы

**Группы (H2) и вопросы (H3), 20–25 всего:**
1. Шақыру / Приглашение — как открывает гость, музыка, шаблоны, вид тоя, язык приглашения, можно ли изменить (только если продакт подтвердит).
2. Тізім және жауап / Список и ответы — несколько составителей, повторы, «Жауап бермегендер», ответ по телефону, «Еске салу».
3. Отырғызу / Рассадка — столы, категории, «Отырғызу реті», номер стола в WhatsApp, печать по столам.
4. Кіреберіс / Вход — помощник, без интернета.
5. Шығындар / Расходы — учёт, ресторан по цене места, Excel.
6. Құпиялық / Конфиденциальность — какие данные храним, кто видит список, удаление. **Каждый ответ согласовать с юристом [ЮРИСТ]**; до этого раздел не публиковать.
7. Баға / Цены — `{PRICE}`, `{FREE}`; не публиковать до Р10.

Правило ответов: 1–3 предложения, факт о продукте, без обещаний сверх таблицы §4 в `home-kk.md`. Вопросы о традициях здесь не отвечаем — ссылки на `/kk/dastur`, `/kk/tilekter`.

- Реальные истории семей без письменного согласия.
