## 4. Структура kk

### Вступление — определение (70 слов)
«Құдалық (кудалык) — күйеу жігіт жағы қыздың үйіне барып, қызды айттыратын және екі отбасы туысатын дәстүр. Құдаларды бас құда бастап барады, қыз жақ дастарқан жайып, шашу шашып қарсы алады.» ✓✓ [S24][S6][S25].

### H2 1. Құда түсу деген не — 150 слов
Күйеудің әкесі не жақын туыстары қыздың үйіне сөз салуға барады; қыздың әкесі келіскен соң құдалық рәсімдері басталады ✓✓ [S24][S6]. Делегацияны бас құда бастайды ✓✓ [S24][S6]; екі жақтың әкелері бір-біріне «бауыздау құда» ✓ [S24]. Бас құдаға тәжірибелі, салт білетін, шешен адамды таңдайды ✓ [S25]. Мақал: «Құда мың жылдық, күйеу жүз жылдық» [S26].

### H2 2. Құдалық тәртібі: қадам бойынша — 300 слов
Список по S25 (inbusiness) и S6 (nur.kz):
1. Күйеудің ата-анасы туыстарымен ақылдасып, кімдер баратынын таңдап, сыйлық (ат, шапан) дайындайды ✓ [S25].
2. Таңдаған «жақсы» күні аттанады ✓ [S25].
3. Қыз жақ шашумен қарсы алады (құрт, ірімшік, қант, кәмпит; бастайтын — ең сыйлы әйел) ✓✓ [S25][S6].
4. Табалдырық аттар: есік алдында әйел «табалдырық» үшін сыйлық сұрайды ✓ [S25].
5. Отырғызып, сыбаға тартады — ет мүшелері дәрежесі мен жасына қарай; шатастыру — қорлау, айып ✓ [S25].
6. Отырған соң екінші шашу ✓ [S25].
7. Құйрық-бауыр: қыздың әкесі келіссе, құйрық-бауыр береді — келісім белгісі ✓✓ [S6][S24].
8. Той мерзімін, той малын, ана сүтін т.б. келіседі ✓✓ [S15][S20].
Домбыра тартылады ✓ [S6]. Құда аттанар, құда тарту, ат байлар аталады, бірақ сипатталмаған [S24] — **не расписывать**.

### H2 3. Құдалыққа кімдер барады — 100 слов
Нақты сан жоқ ✓ [S25]. (Цифра 10–15 — о қыз ұзату [S20], **не переносить** на құдалық.)

### H2 4. Не апарады және киіт деген не — 250 слов
- Сыйлықтар: ат, қонақтарды киіндіруге шапан (бұрын) ✓ [S25].
- **Киіт** — екі отбасының құдалықтан кейінгі бір-біріне сыйы, «жақсы қарым-қатынас пен жастарға көмек үшін»; **бас киіт** — бас құдаға, **аяқ киіт** — қалғандарына; құны қонақтың мәртебесіне қарай; бұрын — тон, кілем, мал, ең төмені — мата ✓ [S26] (к.филол.н. А. Ақыжанова). Қыздың ата-анасына күйеу жақтан киіт ✓ [S15] → ✓✓.
- «Киіт кигізу — қыз сату деген сөз емес» ✓ [S26].
- Бүгін сыйлық — отбасының мүмкіндігіне қарай; біреулер жастарға ақша жинайды, біреулер киіттен бас тартады ✓ [S26].
- Суммы — **не писать**.

### H2 5. Құдаларды қайда отырғызады — 100 слов
Құда шақырыста төрге құдалардың үлкені отырады; үй иелерінің туыстары — төменірек ✓ [S39] («бір деректе»). Ссылка → `/kk/otyrgyzu-jospary`.

### H2 6. Даулы және қазіргі әдеттер — 120 слов
«Көрпе жабар» — шынымен болған әзіл-ырым, бірақ оны мейрамханада жұрт алдында жасауды этнограф Болат Бопайұлы «дарақылық» деп атаған ✓ [S27]. Нейтрально.

### H2 7. Құдалықтан кейін: сырға салу — 60 слов + ссылка `/kk/dastur/syrga-salu`
