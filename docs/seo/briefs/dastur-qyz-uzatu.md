## 1. Цель, интент, читатель

- **kk «қыз ұзату» (1 300) + qyz uzatu (170) + дәстүрі (140):** семья невесты и гости: что за той, этапы, кто приезжает, как принимают сватов, что такое жасау и киіт.
- **ru «кыз узату что это» (260), «сценарий кыз узату» (40), «как проходит» (20):** русскоязычные гости, родня жениха из других регионов, молодые. Пик — июль–сентябрь.
- **Цель:** доверие + мягкий CTA «Қыз ұзатуға шақыру жасау».

## 2. Ключи

**kk:** **қыз ұзату** (1 300) — title, H1, первый абзац, 4 H2, всего 7–9; қыз ұзату дәстүрі (140) — H2 №1 или первый абзац; қыз ұзату салты (20), қыз ұзату тойы (20) — по 1; qyz uzatu (170) — **один раз** в H2 №1: «латынша жазылуы — qyz uzatu»; kyz uzatu (20), «кыз узату дастури» (10) — не упоминать.
**ru:** **кыз узату что это** (260) — title, H1 в форме «Қыз ұзату (кыз узату): что это…», первый абзац; сценарий кыз узату (40) — H2 «Как проходит вечер сегодня» (сказать прямо: «единого сценария в традиции нет»); кыз узату традиции (30), как проходит (20) — H2. «кыз узату» без казахских букв: title, description, 1 раз в тексте.

## 4. Структура kk

### Вступление — определение (60–80 слов)
«Қыз ұзату — қалыңдықтың ата-анасы қызын күйеу жағына аттандыратын той. Қыз туған үйімен, туыстарымен қоштасады, ата-анасы ақ батасын береді.» ✓✓ [S6][S20][S19].

### H2 1. Қыз ұзату деген не — 200 слов
- Тойды қыз жағы жасайды; бастамашысы — қыздың ата-анасы ✓ [S20]. Екі жақ көбіне бөлек той жасайды: қыз ұзату — қыз жақта, үйлену тойы — күйеу жақта ✓✓ [S6][S20].
- Екі әулеттің одағы, жаңа отаудың басы ✓✓ [S19][S20].
- «Латынша жазылуы — qyz uzatu» (одна фраза).

### H2 2. Құдалықтан ұзатуға дейін: кезеңдер — 250 слов
Нумерованный список (порядок общий, без дат) ✓✓ [S6] + файлы:
1. Құда түсу, құдалық [S6][S24][S25] → ссылка `/kk/dastur/qudalyq`
2. Сырға салу [S6][S16] → `/kk/dastur/syrga-salu`
3. Қалың мал — бүгін көбіне оңтүстікте және ақшалай, «төлемнен гөрі көмек» ✓✓ [S6][S19]; кей өңірлерде (солтүстікте) қалың мал орнына «ана сүті» ✓ [S7] — «кей өңірлерде».
4. Қыз ұзату
5. Үйлену тойы және беташар — күйеу жақта ✓✓ [S6][S3] → `/kk/dastur/betashar`
Абзац: қыз ұзатудың орны мен уақыты құда түскенде келісіледі; көбіне үйлену тойынан бір апта бұрын өткізу ыңғайлы деп саналады ✓ [S20] — «көбіне», не правило. Ұзату алдында қыздың жеңгесі күйеу жақтың тұрмысымен танысуға барады («қыз танысу») ✓ [S19] — «бір деректе».

### H2 3. Қыз ұзатуда не болады: сыңсу, жар-жар, қоштасу — 250 слов
- Қыздың туған үйімен, туыстарымен қоштасуы ✓✓ [S6][S19][S22].
- Қалыңдықтың алдына ақ жол төселеді ✓ [S6] — «бір деректе».
- **Сыңсу** — қоштасу әні; оны қыздың апалары не жеңгелері айтып, қалыңдықпен бірге үйлерді аралаған; қазір көбіне қыз аттанар кезде айтылады ✓ [S22]. Бір деректе анасы сыңсумен шығарып салады делінеді [S19]. Текст не приводить.
- **Жар-жар** — күйеу жақтың жігіттері (көңілді) мен қыздың құрбылары, жеңгелері (мұңды) кезек айтатын ән-диалог; өңірлерде қайырмасы «үкі-ау», «ай-ау» ✓ [S21]. Текст не приводить.
- Қалыңдық артына қарамау керек деген ырым бар ✓ [S6] — «ырым», «бір деректе».
- Неке: бір деректе молда некені қыздың ауылында қияды делінеді ✓ [S19]; қазір неке қиюдың уақыты мен орны әртүрлі — ссылка на `/kk/dastur/uilenu-toi` (после публикации).

### H2 4. Қазіргі қыз ұзату кеші қалай өтеді — 150 слов
**Важно:** дереккөздерде «сағат бойынша бағдарлама» жоқ — бұл асабаның тәжірибесі. Писать как практику: «Қазір көп отбасы тойханада кеш өткізеді: қонақтарды қарсы алу, тілектер, ән-би, сыңсу мен қоштасу». Без часов и обязательного порядка. Блок «Біздің кеңес»: «Кеш бағдарламасын асабамен алдын ала келісіп, қоштасу сәтін кешке қалдырмаңыз» — только как совет (или не давать совет вовсе).

### H2 5. Қыз ұзатуға кімдер келеді — 180 слов
- Күйеу жақтан: жақын, көбіне жасы үлкен туыстар, әдетте құдалыққа барғандар; шамамен 10–15 адам; бастан-аяқ қатысады ✓ [S20] — «әдетте».
- Күйеудің алыс туыстары мен достары — үйлену тойына ✓ [S20].
- Күйеудің қатысуы туралы деректер біркелкі емес — **не писать**.
- Қыз жақтың қонақтары (туыстар, нағашылар, көршілер) — «әр отбасы өзі шешеді»; ереже жоқ.

### H2 6. Құдаларды қалай күтеді және қайда отырғызады — 150 слов
- Күйеу жақтың сыйлықтарын рәсімге қатысқан қыз жақтың әйелдері алады ✓ [S20].
- Қонақтарға шағын сыйлықтар («тойбастар» деп те атайды) дайындайды ✓ [S20][S48] — одна фраза.
- Отырғызу (традиция дома): құда шақырыста төрге құдалардың үлкені отырады ✓ [S39] — «бір деректе». Тойханадағы орындар туралы дереккөз жоқ — «бүгін көбіне құдаларды төрге жақын отырғызады» как практика, явно. Ссылка «Отырғызу жоспары» → `/kk/otyrgyzu-jospary`.
- **Не писать:** «жастар төрде отырады».

### H2 7. Қыздың жасауы және киіт — 180 слов
- Жасау — көрпе-төсек, киім, кілем, әшекей ✓ [S19]; бүгін — әшекей, киім, жиһаз, техника ✓ [S6] (✓✓ по сочетанию).
- Киіт — екі отбасының бір-біріне сыйы; бас киіт — бас құдаға, аяқ киіт — қалғандарына; «киіт кигізу — қыз сату емес» ✓ [S26] (филолог А. Ақыжанова). Ссылка `/kk/dastur/qudalyq`.
- Ұзатуда қалыңдық көбіне ұлттық көйлек киеді; анасы сәукелемен шығарып салады ✓ [S19] — «бір деректе».

## 6. FAQ kk

1. Қыз ұзатуды кім жасайды? — қыздың ата-анасы [S20].
2. Қыз ұзату мен үйлену тойының айырмашылығы? — ұзату қыз жақта, үйлену тойы күйеу жақта [S6][S20].
3. Күйеу жақтан кімдер келеді? — жақын, көбіне үлкен туыстар, 10–15 адам [S20].
4. Сыңсу деген не? [S22]
5. Жар-жар қашан айтылады? — қалыңдық аттанар алдында [S21].
6. Қыз ұзату үйлену тойынан қанша бұрын? — көбіне бір апта (ереже емес) [S20].
7. Қыз ұзатуда кеш бағдарламасы бар ма? — дәстүрде бекітілген бағдарлама жоқ; асабамен келіседі.
