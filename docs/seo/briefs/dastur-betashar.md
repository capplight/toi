## 1. Цель, интент, читатель

- **kk «беташар» (1 900) + «беташар текст» (590) + «беташар деген не» (140):** семья жениха готовит свадьбу, молодые и их родители хотят понять смысл, порядок, что подготовить; многие ищут **текст жыра**. Полный народный текст мы дадим только из сборника через О8 — пока страница закрывает структуру жыра.
- **ru «беташар что это» (20), «беташар традиция» (20):** русскоязычные гости и молодые.

## 2. Ключи

## 4. Структура kk

### Вступление — определение (60–80 слов)
Своими словами: «Беташар — келінді күйеу жағының туыстарымен таныстырып, бетін ашатын үйлену тойы рәсімі. Ақын жыр арқылы туыстарды атайды, келін әрқайсысына сәлем салады, соңында келіннің беті ашылады.» ✓✓ [S1][S3][S4]. Екі мәні: келінді елге таныстыру және келінге келген жерін таныстыру ✓ [S4].

### H2 1. Беташар деген не — 200 слов
- 2024 жылы ЮНЕСКО-ның адамзаттың материалдық емес мәдени мұрасының репрезентативтік тізіміне енді (шешім 19.COM 7.b.45, Асунсьон, Парагвай) ✓✓ [S1][S2].
- ЮНЕСКО сипаттамасы бойынша, рәсім орта ғасырларда, күйеу қалыңдықты тойға дейін сирек көрген кезде пайда болған ✓ [S1] — **обязательно со ссылкой: «ЮНЕСКО сипаттамасында…»**.
- Білім әжеден немереге беріледі; ақындар мен той киімін тігетін шеберлер шәкірт тәрбиелейді ✓ [S1].
- С. Кенжеахметұлы («Жеті қазына»): «Жаңа түскен келінді беташар дәстүрі жасалмай ешкім көре алмайды» ✓ [S4] — короткая цитата, атрибутирована.
- Мақал: «Келіннің бетін кім ашса — сол ыстық» [S3] (халық аузынан).

### H2 2. Беташар қашан өтеді және кім айтады — 180 слов
- Үйлену тойы күні, күйеу жақта ✓✓ [S6][S3].
- «Қазір беташар көбіне той асының алдында өткізіледі» ✓ [S3]. Кей өңірлерде (оңтүстікте) тойдан бөлек, солтүстікте той кезінде ✓ [S7] — только «кей деректер бойынша, өңірге қарай әртүрлі». **Не писать** «міндетті түрде тойдың басында / соңында».
- Жырды ақын (жыршы) айтады ✓✓ [S1][S3][S4]. Той иесі жыршыға беретін сыйлығын алдын ала айтады ✓ [S3].

### H2 3. Беташар тәртібі: келін кімдерге сәлем салады — 300 слов
Нумерованный список по research (порядок ЮНЕСКО + детали):
1. Келінге бас киім мен жабу кигізіледі (ЮНЕСКО — қалыңдықтың анасы) ✓ [S1]; басына үлкен ақ орамал жабылады, беті көрінбейді ✓ [S4].
2. Келінді екі әйел (абысындары / екі сыйлы келіншек) алып шығады ✓✓ [S3][S4].
3. Орамалдың ұшы теңгемен байланып, қамшыға, домбыраға не оқтауға ілінеді; оны кішкентай бала ұстайды ✓ [S4].
4. Ақын ата-енесін, үй ішін, күйеуінің туыстарын, ауылдың сыйлы адамдарын атайды; аталған адам шығып көрімдік береді, келін сәлем салады ✓✓ [S1][S3][S4].
5. Соңында ақын келінге ақ тілек айтады ✓ [S4].
6. Келіннің беті қамшының немесе домбыраның сабымен ашылады ✓ [S4]; ЮНЕСКО: жабуды ақын көтереді ✓ [S1]. ⚠ «Енесі домбырамен ашады» [S6] — **не писать**.
7. Енесі келінді маңдайынан иіскейді, шашу шашылады ✓✓ [S4][S5][S1].
8. Күйеу қалыңдықты қолынан алады (ЮНЕСКО) ✓ [S1].
9. Кейін келін шай құяды, үлкендер бата береді ✓ [S3].
Абзац после списка: «Келін кімдерге сәлем салады?» — ата-ене, үй іші, күйеуінің ағайын-туыстары, ауылдың ардақты адамдары ✓✓ [S3][S4].

### H2 4. Беташар жыры: құрылымы — 250 слов
- Құрылымы ✓✓ [S3][S4]: басталуы мен сәлемдесу → туыстарды бір-бірлеп таныстыру (мінездемесімен) → келінге өсиет (ата-енені сыйлау, сөзді жұмсақ айту, үлкендерге тік қарамау) → ақ тілек.
- Жыр ауызша айтылады, ақын дайындығына сүйеніп көбіне суырып салады; негізгі өзегі тұрақты ✓ [S3].
- Жырдың тәрбиелік мәнін М. Әуезов атап өткен (S3 бойынша) ✓.
- **Мәтін туралы ескерту (писать так):** «Беташар жыры — халық шығармашылығы, оның нұсқалары көп. Халықтық нұсқаның толық мәтінін {сборник} бойынша беріп отырмыз» — **только когда О8 даст текст**. До этого: «Толық мәтінді академиялық жинақтан тексеріп, жақын арада қосамыз» не писать (обещание); просто без текста.
- Ілияс Жансүгіровтің «Беташары» — авторлық шығарма; **мәтінін бермейміз** (охрана до 31.12.2027). Можно одной фразой: «Ілияс Жансүгіровтің "Беташар" өлеңі де кең тараған; ол — авторлық шығарма».
- Беташар әуені туралы дау: эстрадалық әуенге айтуды сынап, Біржан сал әндерін ұсынғандар бар ✓ [S8] — одна фраза как пример спора (источник низкой надёжности: «баспасөзде айтылған пікір»).

### H2 5. Беташарға не дайындау керек — 150 слов + таблица + PDF
Таблица из research: ақ орамал / жабу ✓✓; қалыңдықтың бас киімі ✓ [S1]; қамшы, домбыра немесе оқтау ✓ [S4]; орамал ұшына теңге ✓ [S4]; шашу (тәтті, тиын) ✓✓; туыстардың көрімдігі ✓✓; жыршыға сыйлық ✓ [S3]; көрімдікке табақ ✓ [S5]. Кей өңірлерде (оңтүстікте) енесі келінге қызыл шапан сыйлайды ✓ [S7] — «кей өңірлерде».

### H2 6. Беташар ақшасы кімге тиесілі — 120 слов
✓ [S5] (этнограф Байахмет Жұмабайұлы): табақтағы ақша жастарға тиесілі, бетін ашқан адамға емес; қонақтарды мақтау сөзбен көп салуға итермелеу — дәстүрді бұрмалау. «Беташар шоуға айналып кетті» деген пікір бар. Подать как мнение этнографа.

### H2 7. Келінге тілек және ақ бата — 80 слов + ссылка
Беташардың соңында келінге ақ тілек айтылады [S4], шайдан кейін үлкендер бата береді [S3]. Ссылки «Келінге тілек» → `/kk/tilekter/kelinge`, «Ақ бата» → `/kk/tilekter/bata`.

## 7. НЕ писать (research)

- Что лицо открывает свекровь.
- «Міндетті түрде тойдың басында / соңында» как правило.
- Длительность, число гостей, стоимость акына.
- Текст Жансүгірова (полностью и строфами) — до 2028.
- Текст Жансүгірова как «халықтық беташар».
- Символику оқтау («үй шаруасына икемді болсын»).
- «Орта ғасырлардан бері» без ссылки на ЮНЕСКО.
- Тексты беташар с сайтов и от современных акынов.
