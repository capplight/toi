## 5. FAQ

1. **Құдалықта не дейді?** — «Құдалық қабыл болсын» [S16].
2. **Бас құда кім?** — делегацияны бастайтын тәжірибелі, шешен адам [S24][S25].
3. **Киіт деген не?** — екі отбасының бір-біріне сыйы; бас киіт — бас құдаға, аяқ киіт — қалғандарына ✓ [S26]; «киіт кигізу — қыз сату емес» [S26].
4. **Құдаларға тілекті кім айтады?** — нақты реті жоқ; көбіне үлкендер.
