## 1. Цель и интент

Страница нужна для блока картинок в выдаче («шақыру билеті», «тойға шақыру», «пригласительные на свадьбу») и чтобы делиться демо в соцсетях. Читатель хочет увидеть шаблон вживую и начать с него.

## 2. Ключи

Основной ключ у всех трёх: kk — «тойға шақыру билеті үлгісі» (в базе отдельно нет; страница держится на кластере «шақыру билеті»), ru — «шаблон приглашения на свадьбу / той». Не переоптимизировать: ключ один раз в H1, один раз в тексте, в alt картинки.

## 4. Структура (каждая страница)

1. H1 + 1 предложение.
2. `<DemoInvite template="…" />` (музыка только по нажатию; ответ «понарошку»).
3. **Қандай / Какой** — 80–120 слов: настроение, цвета, конверт и печать, заставка — строго по таблице DESIGN §10. Факт «Казахстан — родина диких тюльпанов» есть в DESIGN §10 как описание дизайнера, а не в research: **не писать** как факт, можно «дала қызғалдақтары» / «степные тюльпаны» без утверждения о родине.
4. **Қай тойға лайық / Для какого тоя** — 40–60 слов (по DESIGN: Ақ шаңырақ — классика; Көк түн — вечерний, строгий; Қызғалдақ — молодёжный, қыз ұзату). Без «дәстүр бойынша».
5. CTA «Осы үлгімен жасау» / «Создать по этому шаблону» (→ `/e/new?template={id}`), «WhatsApp-қа жіберу» / «Отправить демо в WhatsApp».
6. Подпись: «Демодағы есімдер, күн мен мекенжай ойдан алынған» / «Имена, дата и адрес в демо вымышленные».
7. Ссылки на два других шаблона и на `/kk/shaqyru` («Барлық үлгілер») / `/ru/priglashenie`.

## 5. НЕ писать

- Реальные имена, телефоны, рестораны в демо.
- «Родина тюльпанов», символику цветов и орнаментов как традицию (в research нет).
- Цену шаблона (`{PRICE}`).
