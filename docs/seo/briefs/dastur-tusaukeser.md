## 4. Структура kk

### Вступление — определение (60–80 слов, для AI Overview)
Своими словами по research: «Тұсаукесер — баланың алғашқы қадамына арналған дәстүр: тәй-тәй басқан сәбидің аяғына ала жіп байлап, оны сыйлы адам кеседі. Бала өмір жолында сүрінбей, адал жүрсін деген ниетпен жасалады.» ✓✓ [S9][S10][S11]. Атауы — «тұсауды кесу» ✓✓ [S10][S18].

### H2 1. Тұсаукесер қашан өткізіледі — 150 слов
- Бала жүре бастағанда (тәй-тәй басқанда) ✓✓ [S9][S10][S11].
- Нақты жас дереккөздерде көрсетілмейді; **формулировка обязательна:** «көбіне бір жас шамасында». Не писать «12 ай», «бір жасында».
- Где: үйде (қонақ аз болса), жазда — саяжайда, аулада, демалыс үйінде ✓ [S11] — «бір деректе айтылғандай».
- Күнін белгілеп, қонақ шақырады ✓ [S10].

### H2 2. Ала жіп нені білдіреді — 180 слов
- Ала жіп — алагөз (түрлі түсті) жіп ✓✓ [S9][S10]; ұзындығы шамамен 1,5 м ✓ [S10] («бір деректе»).
- Мәні — адалдық: «ешкімнің ала жібін аттамасын» ✓✓ [S9][S10].
- Бұрын тұсауды малдың тоқ ішегінен (байлыққа) немесе көк шөптен (ұрпақтың көп болуына) жасаған ✓✓ [S9][S10].
- Түстер саны: **не писать** («2–3 түс» и «8 түс» в одном слабом источнике S11 противоречат).

### H2 3. Тұсауды кім кеседі — 180 слов ⚠
Писать только общее для всех источников: «Тұсауды ата-ана таңдаған сыйлы, дені сау, пысық адам кеседі» [S9][S10][S11].
Можно добавить как варианты, явно: «Бір деректерде көбіне көп балалы, тәжірибелі үлкен әйел кеседі делінеді [S9], енді бірінде қыз балаға — әйел, ұл балаға — ер адам [S13]. Нақты бір ереже жоқ.»
Чем режут ⚠: «Көбіне пышақпен кеседі [S9][S11], кей деректерде қайшы да аталады [S10]». **Не писать** «қайшымен кесуге болмайды».
Кесушіге сыйлық береді ✓✓ [S9][S10]; көбіне көйлек немесе аяқкиім ✓ [S10].
Этнограф Т. Қартаева: дәстүрде тұсау кескені үшін ақша алмаған, оны әншілер мен блогерлер емес, сыйлы үлкендер кескен ✓ [S12] — подать как мнение этнографа.

### H2 4. Тұсаукесер тәртібі: қадам бойынша — 250 слов
Нумерованный список (подтверждённые шаги [S9][S10][S11]):
1. Ақ мата немесе кілем төселеді (ақ жол) ✓✓
2. Баланың аяғына ала жіп байланады ✓✓
3. Сыйлы адам жіпті кесіп, тілек айтады ✓✓
4. Екі адам баланы қолынан жетелеп, ақ жолмен жүргізеді ✓✓ (S13: бірнеше қадамнан кейін жібереді)
5. Шашу шашылады ✓✓
6. Кесушіге сыйлық беріледі ✓✓
Қосымша: жолдың соңына ақша, қамшы, кітап қояды, бала біреуін таңдайды; ақша — бай, қамшы — ел басқарады, кітап — білімді болады ✓✓ [S9][S11]. «Бұрын алдында анасы құшағын жайып тұрған, қазір — заттар» ✓ [S9]. Сверх этих трёх предметов значения **не давать**.
Кей өңірлерде балалар жарысып, жеңімпаз жіпті шешіп, сыйлық алады ✓ [S10] — «кей өңірлерде».

### H2 5. Тұсаукесерге не дайындау керек — 150 слов + таблица + PDF
Таблица из research (раздел «Не дайындау керек»): ала жіп (~1,5 м); пышақ (кейде қайшы); ақ мата не кілем; шашу (құрт, май, кәмпит, ойыншық, асық, сылдырмақ — ✓ S10); дастархан; кесушіге сыйлық; таңдауға арналған заттар (ақша, қамшы, кітап); балаға ұлттық киім (✓ S11). Кнопка «Тізімді басып шығару» (PDF).

### H2 6. Тұсау кесерде айтылатын тілек — 200 слов + 8–10 текстов
- Народные возгласы (халық аузынан): «Жүйрік бол!», «Шауып кет!» ✓ [S10].
- Тұсау кесу кезінде «Тұсаукесер» әні айтылады ✓ [S10] — без текста.
- 8–10 оригинальных тілек: от кесуші (3), от ата-әже (3), от гостей (2–4). Образы: ақ жол, сүрінбей жүру, адал болу (ала жіп), жүйрік бол, білімді / ел басқаратын (предметы) ✓✓ [`research/tilek-besik-toi.md`].
- **Жыр «Қаз-қаз балам…» не публиковать** (текст не верифицирован). Если О8 даст текст из сборника — добавить H3 «Тұсаукесер жыры» с указанием сборника.

### H2 7. Бүгінгі тұсаукесер: жұлдыздар мен ақша — 120 слов
✓ [S12]: тұсау кесуге танымал әншілер мен блогерлерді шақыру — 300 мың теңгеден 3 млн теңгеге дейін (агенттер мен орындаушылар, 2023 жылғы шілде). Этнограф Т. Қартаева: «Тұсаукесер қазіргі кезде — трансформацияға ұшыраған дәстүрдің бірі». Тон нейтральный, без осуждения семей. «Турецкий актёр за $200 000» — **не писать** (не проверено).

## 6. FAQ (kk; ru — те же 4 первых)

1. **Тұсаукесер қай жаста жасалады?** — бала жүре бастағанда; нақты жас көрсетілмейді, көбіне бір жас шамасы.
2. **Тұсауды кім кеседі?** — ата-ана таңдаған сыйлы, дені сау, пысық адам [S9][S10][S11].
3. **Ала жіп нені білдіреді?** — адалдықты [S9][S10].
4. **Тұсауды қайшымен кесуге бола ма?** — дереккөздер әртүрлі: көбі пышақ дейді [S9][S11], кейбірі қайшыны да атайды [S10].
5. **Тұсау кесушіге не сыйлайды?** — сыйлық, көбіне көйлек не аяқкиім [S9][S10].
6. **Тұсау кесуге ақша төлеу керек пе?** — дәстүрде жоқ (этнограф Т. Қартаева) [S12].

## 7. НЕ писать (из research)

- Точный возраст («дәл бір жасында», «12 айда»).
- «Қайшымен кесуге болмайды».
- Пол режущего как правило.
- «Тұсау кесілмесе, бала қисық табанды болады» [S11 — слабый].
- Текст «Қаз-қаз балам» и любого тұсаукесер жыры без сборника.
- Значения предметов сверх трёх (ақша, қамшы, кітап).
- Число цветов нити.
- История про турецкого актёра.
