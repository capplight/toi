## 1. `/ru/spisok-gostei` + `/kk/qonaqtar-tizimi`

- **Интент:** «список гостей на свадьбу» (110), «… шаблон» (30). kk «қонақтар тізімі» — 0. Человек ищет шаблон таблицы (Excel) или способ вести список.
- **Ключи ru:** **список гостей на свадьбу** — title, H1, первый абзац, 2 H2; шаблон — H2 «Шаблон».
- **Title ru:** Список гостей на свадьбу: шаблон и онлайн
- **Description ru:** Список гостей на свадьбу и той: шаблон, который можно заполнять вместе с родителями, ответы гостей, повторы, выгрузка в Excel и итог для ресторана.
- **H1 ru:** Список гостей на той вместе с родителями
- **Title kk:** Қонақтар тізімі: ата-анамен бірге толтыру
- **Description kk:** Тойға қонақтар тізімі: әкесі, анасы, жастар — әркім өз тізімін толтырады. Ұқсас қонақтар, жауаптар, Excel және мейрамханаға арналған сан.
- **H1 kk:** Тойға қонақтар тізімі
- **Структура ru:** вступление → H2 «Почему список тоя — это 3 списка» (папа, мама, молодые — продукт) → H2 «Что записывать о каждой семье» (**«Наш совет»**: имя семьи, телефон, число мест, категория) → H2 «Шаблон списка гостей» (если продакт даст Excel-шаблон для скачивания — ссылка; иначе «выгрузка в Excel из {BRAND}») → H2 «Повторы и семьи» → H2 «Ответы и итог для ресторана» → H2 «Вопросы» (3) → CTA.
- **Факты о традиции:** не нужны. Если упоминается деление по категориям — «Құдалар, Өз туыстар, Нағашылар — категории по умолчанию, порядок меняете вы» (`research/fact-check-existing.md` §2: порядок не правило).
- **НЕ писать:** «сколько гостей принято звать», «процент неявки» (нет данных), «единица счёта — семья по традиции».

## 2. `/ru/byudzhet-toya` + `/kk/toi-shygyny`

- **Интент:** «сколько стоит свадьба в казахстане» (20), «сколько стоит той» (20). Калькулятор бюджета — 0 (после пилота). Страница функции учёта расходов.
- **Ключи ru:** **бюджет тоя** (в title), «сколько стоит той» — H2.
- **Title ru:** Бюджет тоя: расходы и учёт в тенге
- **Description ru:** Как вести расходы на той: ресторан по цене за место, асаба, наряды, оформление. Учёт расходов вместе с родителями и итог в тенге в одном месте.
- **H1 ru:** Бюджет тоя: сколько стоит той и как вести расходы
- **Title kk:** Той шығыны: шығындарды есепке алу
- **Description kk:** Той шығынын қалай жүргізу керек: мейрамхана бір орын бағасымен, асаба, киім, безендіру. Шығындарды ата-анамен бірге есептеу — теңгемен.
- **H1 kk:** Той шығыны
- **Структура:** вступление → H2 «Из чего складывается бюджет» (категории расходов из продукта — `STYLE_GUIDE` 13.6; без цен) → H2 «Сколько стоит той» — **только с цифрами, у которых есть источник и год** (данные из `research/toi_pains_research.md` о цене места по городам — SEO-менеджер передаст выписку с источниками перед написанием; без выписки раздел не писать) → H2 «Как вести расходы в {BRAND}» → H2 «Вопросы» (3) → CTA.
- **НЕ писать:** «сколько дарить на той» (нет данных, тема спорная), «средняя свадьба стоит …» без источника, кредиты, оценки «дорого/дёшево» (STYLE_GUIDE 12).
