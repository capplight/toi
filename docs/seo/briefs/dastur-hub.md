## 1. Интент и читатель

kk-хаб собирает статьи и показывает свадебный и детский циклы. ru: «казахская свадьба традиции», «казахские свадебные традиции», «сценарий казахской свадьбы», «калым у казахов» (по 20).

## 2. Ключи

kk: основного ключа с объёмом нет; «қазақ той дәстүрлері» (0) — title/H1.
ru: **казахская свадьба традиции** / **казахские свадебные традиции** (20 / 20) — title, H1, первый абзац; сценарий казахской свадьбы (20) — H2 (с ответом «единого сценария нет»); калым у казахов (20) — абзац о қалың мал.

## 3. Метаданные

**kk**
- **Title:** Қазақ тойының дәстүрлері
- **Description:** Қазақ тойының дәстүрлері: құда түсу, сырға салу, қыз ұзату, үйлену тойы мен беташар, бесік той, тұсаукесер, сүндет той. Әр дәстүр туралы толық мақала.
- **H1:** Той дәстүрлері: құдалықтан беташарға дейін

**ru**
- **Title:** Казахские свадебные традиции по порядку
- **Description:** Казахская свадьба: традиции по порядку — құда түсу, сырға салу, қалың мал, қыз ұзату, свадьба и беташар. Детские обряды: бесік той, тұсаукесер.
- **H1:** Казахские свадебные и семейные традиции

## 4. Структура (kk; ru — та же логика своими словами)

- **Вступление 80 слов.**
- **H2 «Үйлену циклы»** — список по порядку ✓✓ [S6] (`dastur-uilenu-toi.md`): құда түсу → сырға салу → қалың мал → қыз ұзату → үйлену тойы / беташар. Каждый пункт — 1 предложение-определение из соответствующего research-файла + ссылка. Абзац о қалың мал (для ru «калым у казахов»): «сегодня в основном на юге и деньгами, скорее помощь, чем выкуп» ✓✓ [S6][S19]. Суммы — не писать.
- **H2 «Бала туғаннан кейінгі дәстүрлер»** — шілдехана → бесік той → тұсаукесер → сүндет той, по одному определению + ссылка.
- **H2 «Той сөздігі»** — ссылка на `/kk/dastur/toi-sozdigi` (после публикации).
- ru: **H2 «Есть ли единый сценарий казахской свадьбы»** — 80 слов: «Единого сценария в традиции нет: есть последовательность обрядов (выше), а программу вечера сегодня обычно составляет асаба».
- **Подпись:** «Мақалаларды тексерген: {REVIEWER}».

## 5. НЕ писать

- Новые факты, которых нет в статьях раздела.
- «Сценарий свадьбы по часам».
- Суммы қалың мал и ана сүті.
- Региональные «правила».
